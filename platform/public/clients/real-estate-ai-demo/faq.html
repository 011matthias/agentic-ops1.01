Frequently Asked Questions

Common questions about the demo workflow, delivery, and extensions.

About the Demo

How fast does the SMS response arrive? ▼
Under 10 seconds in most cases. The bottleneck is the OpenAI API call (2-5 seconds) plus Twilio delivery (1-3 seconds). In a live demo, this feels nearly instant.
What if the SMS fails? ▼
The Google Sheet row turns red and logs the Twilio error code. Common causes are invalid phone numbers or Twilio account balance. The error is visible immediately, nothing fails silently.
Can I use this with any property listing? ▼
Yes. The PDF ingestion workflow handles any property listing flyer. Drop the PDF into the Google Drive folder, wait about 30-60 seconds for ingestion, and the demo is ready for the new property.
What if the lead asks something not in the PDF? ▼
The AI is prompted to respond honestly when it cannot find the answer. Instead of guessing, it will say something like "I do not have that detail in the current listing. An agent will follow up with you shortly."

Technical Details

How fast does the vector store refresh? ▼
30-60 seconds for a typical property listing PDF (1-5 pages). A status indicator in the Google Sheet shows when ingestion is complete and the demo is ready.
What about SMS character limits? ▼
The AI prompt is tuned to keep responses under 160 characters (one SMS segment). This avoids split messages and keeps the response clean on the recipient's phone.
Do I need to host n8n myself? ▼
You can use n8n cloud (hosted) or self-hosted. Both work. If you already have an n8n instance, I will build on that. If not, I can set it up on n8n cloud during Day 1.
What AI model does it use? ▼
OpenAI GPT-4o-mini by default. It is fast, accurate, and cost-effective for short SMS responses. You can switch to GPT-4o for more complex answers if needed.

Working Together

Why $650 instead of hourly? ▼
This is a defined deliverable, not ongoing work. Fixed-price means you pay for the result, not the hours. No tracking, no surprises. If the engagement grows into ongoing work after the demo, we switch to hourly terms.
What do you need from me to get started? ▼
Three things: your API keys (Twilio, OpenAI, Google), a sample property listing PDF, and access to your n8n instance (or I set one up). Use the onboarding form to share these securely.
Can I add more features later? ▼
Yes. The demo is built modularly. Multi-property support, CRM integration, analytics, and a branded interface are all natural extensions. We can scope those separately after the core demo is working.
What if I need changes after delivery? ▼
Post-delivery support is included for questions during your first live demo. If you need structural changes (new features, different integrations), we scope those as a follow-up project.

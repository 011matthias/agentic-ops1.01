5-Day Delivery Plan

From kickoff to working demo, ready for your first live meeting.

Day-by-Day Breakdown

Each day has a single focus and a concrete deliverable. Nothing moves to the next day until the current day's test passes.

1
Day 1 -- Environment and Trigger
n8n environment setup. Google Sheets trigger wired to the lead response workflow. Twilio SMS node tested with a real outbound message to confirm credentials and routing.
2
Day 2 -- AI Agent and RAG
AI Agent node configured with the Simple Vector Store. Property PDF ingested and vector store populated. First end-to-end RAG query tested -- question in, answer grounded in the PDF out.
3
Day 3 -- Prompt Tuning and End-to-End Test
AI prompt tuned for concise, professional SMS responses. White-glove tone calibrated so replies read like a knowledgeable human, not a chatbot. Full end-to-end test run: Google Sheet row added, AI generates answer, Twilio sends the SMS.
4
Day 4 -- Error Handling and Property Swap
Error handling added: failed rows turn red with a logged error message, fallback SMS sent if AI returns empty. Property ingestion workflow built and tested with a second PDF to confirm the swap process works with no configuration changes.
5
Day 5 -- Handoff
Loom walkthrough recorded covering both workflows. Handoff documentation written. Final test run using your property PDF and your phone number to confirm everything works end to end before delivery.

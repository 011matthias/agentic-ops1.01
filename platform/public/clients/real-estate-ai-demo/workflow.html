Three Nodes in the Critical Path

For the lead response, only three nodes matter: Sheets Trigger -- AI Agent -- Twilio. Every other node is logging or error handling. Fewer moving parts means fewer failure points during a live meeting.

n8n Node Configuration

Every node in both workflows is configured entirely through n8n's UI -- no custom code required. The table below shows the key settings for each node.

Node Workflow Purpose Key Configuration
Google Sheets Trigger Lead Response Fires when a new row is added to the demo Sheet Sheet ID from your Google account; Watch: new rows; Columns: lead_name, phone, question
AI Agent Lead Response Queries vector store and composes an SMS-length response Model: GPT-4o-mini; System prompt: white-glove assistant, 160-char limit; Tool: Simple Vector Store retriever
Simple Vector Store Lead Response Retrieves the most relevant chunks from the loaded property PDF In-memory store (persists until workflow restart); Top K: 3; Embedding: OpenAI text-embedding-3-small
Twilio Lead Response Sends the AI response as an SMS to the lead's phone Credential: Twilio account SID + auth token; From: your Twilio number; To: {{$json.phone}}; Body: {{$json.response}}
Google Sheets (Update) Lead Response Writes response and status back to the triggering row Match on row number; Write: response column = AI output, status = "sent"; Error branch writes status = "error"
Google Drive Trigger Ingestion Detects new PDFs dropped into the property folder Folder ID: your "Property PDFs" folder; Event: file created; Filter: mime type = application/pdf
PDF Extract (Binary) Ingestion Reads and extracts text from the PDF binary Input: file binary from Drive Trigger; Output: extracted text string
Recursive Text Splitter Ingestion Splits the listing text into overlapping chunks for the vector store Chunk size: 500 tokens; Chunk overlap: 50 tokens; Separator: paragraph breaks preferred
Credentials Are Node-Level

Each node stores its credentials separately in n8n. You will configure Twilio credentials once in the Twilio node, Google credentials once in each Google node. No environment files or config scripts needed.

Demo Flow

This is the exact sequence to run the demo in a meeting. Practice it twice before the first real meeting -- the timing is part of the impact.

  1. 1
    Open the Google Sheet on screen
    Share your screen showing the demo Sheet. Point out the three columns: lead name, phone, and question. Explain that this is the only interface the agent needs -- no apps, no dashboards, just a spreadsheet they already know how to use.
  2. 2
    Add a row with a real question
    Type a lead name (use a real or fictional name), a phone number reachable in the room (your phone, or a colleague's), and a question about the loaded property. Good questions: "Does it have a pool?", "What are the HOA fees?", "How many bedrooms?" -- things answerable from the listing flyer.
  3. 3
    Watch the SMS arrive
    In under 10 seconds, the phone in the room receives an SMS with a professional, specific answer. Put the phone on the table face-up before adding the row so the audience sees the notification arrive. Do not rush this moment -- let it land.
  4. 4
    Show the Sheet row update
    Switch back to the Sheet. The row now shows the AI response text in the response column and "sent" in the status column. This proves the system logged the interaction -- useful for follow-up and conversation history.
  5. 5
    (Optional) Show the PDF swap
    If the prospect asks how you handle multiple listings, switch to Google Drive, drop a different property PDF into the folder, and watch the Control tab update to "ready" within seconds. Then ask a question about the new property -- the AI answers from the new listing. This closes the "how does it scale?" question before it is asked.
Reset Between Meetings

Clear the question rows from the demo Sheet (keep the header), confirm the Control tab shows the right property, and you are ready for the next meeting. Takes under 60 seconds.

API Requirements

Four integrations are required. All are standard paid accounts with free tiers available for testing. The Onboarding page has a secure form for sharing these credentials.

Twilio
SMS delivery
  • Account SID Found on the Twilio Console dashboard. Starts with "AC".
  • Auth Token Found next to Account SID on the Console dashboard.
  • Phone Number A Twilio-purchased number in E.164 format (e.g. +15551234567). Used as the SMS sender.
OpenAI
AI responses and embeddings
  • API Key From platform.openai.com under API Keys. Used for both GPT-4o-mini (responses) and text-embedding-3-small (vector store).
  • Usage Each demo costs roughly $0.002 -- $0.005 in API calls. A $10 credit covers hundreds of demos.
Google
Sheets and Drive
  • Service Account A Google Cloud service account with Sheets API and Drive API enabled. I will walk through setup in the Loom walkthrough.
  • JSON Key The downloaded service account JSON key file. Used to authenticate both Google nodes in n8n.
  • Sheet ID The ID from your demo Google Sheet URL. Shared with the service account email.
n8n
Workflow automation platform
  • Instance n8n Cloud (n8n.io) or self-hosted. Cloud is easiest -- $20/month, no server management.
  • Version n8n 1.x required for the AI Agent node and Simple Vector Store. Cloud is always up to date.
  • Access I will need editor access to your n8n workspace to deploy and test the workflows.
Total Monthly Running Cost

Twilio: ~$1/month for the number + pennies per SMS. OpenAI: under $1/month for typical demo usage. n8n Cloud: $20/month if you do not have it already. The demo costs almost nothing to run once built.

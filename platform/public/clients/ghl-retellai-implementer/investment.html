Pricing Structure

There are two parts to this arrangement. A one-time setup fee covers everything needed to get a new client environment running. A monthly retainer per active client covers everything that comes after.

One-time
$415 per client setup
Everything from snapshot clone to first live call test.
  • GHL snapshot clone and post-snapshot reconfiguration
  • Retell AI agent configuration (system prompt, dynamic variables, webhook setup)
  • n8n workflow creation (webhook triggers, API calls, IF filtering, error handling)
  • Full end-to-end test of the call flow
  • Documentation of the setup (webhook URLs, credentials used, workflow IDs)
Monthly
Retainer per active client
Ongoing maintenance, changes, and monitoring. Rate discussed per your active client count.
  • 2-3 change requests per client per week
  • Retell prompt refinements and edge case handling
  • n8n workflow updates and debugging
  • GHL pipeline and sequence adjustments
  • Proactive error monitoring
  • Post-go-live support included, no time-limited windows
How the model scales

The per-setup fee only applies when you onboard a new client. The monthly retainer adjusts with your active client count. If a client churns, that retainer drops. You're only paying for active environments, not fixed overhead.

What's Not Included

Being direct about scope avoids mismatched expectations. This is a technical implementation role, not a general-purpose contractor role.

  • Client-facing communication. The posting states this is not a client-facing position. I won't be communicating with your clients directly. All communication goes through your team.
  • Design and branding work. Landing pages, visual assets, or GHL funnel design aren't in scope. I configure and integrate, I don't design from scratch.
  • Snapshot creation from scratch. I work from your existing master snapshots. Post-clone reconfiguration and per-client customisation are included. Building new snapshots from zero isn't.

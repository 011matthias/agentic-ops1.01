Phase 1: Foundation (Week 1)

The infrastructure layer. By end of Day 5, GHL is configured, webhooks are live, and n8n can receive messages and send responses through GHL's Conversations API.

Day 1–2
GHL + Infrastructure
  • Sub-account setup, pipelines, custom fields, tags
  • Webhook endpoints configured
  • n8n instance deployed
  • API connections tested
Day 3–4
Orchestration Layer
  • n8n webhook receivers
  • GHL API v2 integration (contacts, conversations, pipelines)
  • Message routing logic
  • Basic reply-and-respond loop working
Day 5
Integration Testing
  • End-to-end message flow: inbound GHL message → n8n → placeholder AI → response via GHL Conversations API
  • All API connections verified
End of Phase 1

GHL is configured, webhooks are live, and n8n can receive messages and send responses. The AI brain is a placeholder at this point — Phase 2 replaces it with the real engine.

Phase 2: AI Brain (Week 1–2)

The intelligence layer. The AI engine is deployed, ingests the sales playbook, and starts handling real conversations with brand personality and objection handling.

Day 6–7
Conversation Engine
  • AI engine deployed (Claude/OpenAI)
  • Sales playbook ingested
  • System prompt with brand personality, tone rules, compliance guardrails
Day 8–9
Objection Handling + Memory
  • Objection library (10–15 common objections)
  • Conversation state machine (cold open → rapport → qualification → offer → objection → close)
  • Conversation memory: AI reads full history before each response
Day 10
Tuning + Live Testing
  • Test conversations with real sales scenarios
  • Tune prompt for tone, response quality, objection handling accuracy
  • Confidence threshold for human escalation
End of Phase 2

The AI brain is live and handling real conversations. It follows the sales flow, handles objections, and sounds like the brand owner. Connected to GHL via n8n — every response is sent through GHL's messaging channels.

Phase 3: Voice + Multimedia (Week 2–3)

The communication layer expands beyond text. Voice notes, multimedia, and context-based medium selection give the AI a human presence.

Day 11–12
Voice Pipeline
  • ElevenLabs voice persona configured (cloned from recording or preset)
  • Twilio integration for voice note delivery (MMS)
  • Inbound voice transcription pipeline
Day 13–14
Multimedia + Context Triggers
  • Media library configured (testimonials, screenshots, process infographic)
  • Context-trigger rules in AI engine: "when prospect asks about results, send testimonial"
  • Voice note triggers: "after 2 unanswered texts, switch to voice note"
End of Phase 3

The system now communicates via text, voice notes, and multimedia. The AI decides which medium to use based on conversation context and prospect behavior.

Phase 4: Follow-ups + Tracking (Week 3)

Autonomous follow-up sequences and conversion detection. The system handles the full lead journey without human intervention.

Day 15–16
Behavior-Based Follow-Ups
  • Three follow-up sequences built in n8n: ghost (no response), clicked-but-did-not-buy, asked-but-did-not-convert
  • Each generates AI-personalized messages
  • Timing and triggers configured
Day 17–18
Conversion Detection
  • GHL pipeline stage change webhooks
  • Purchase/booking/community-join detection
  • Auto-stop sales messaging
  • Onboarding workflow triggers
  • Activity log per lead
End of Phase 4

The system runs the full lead journey autonomously: conversation → follow-up → conversion detection → onboarding handoff. Pipeline tracking and activity logging are live.

Phase 5: Snapshot + Polish (Week 3–4)

The system is production-ready. This phase creates the snapshot for cloning and documents everything for handoff.

Day 19–20
Snapshot + Provisioning
  • GHL snapshot created (captures all CRM config)
  • Provisioning script built (Twilio number, ElevenLabs persona, n8n webhooks, AI config per client)
  • Test: deploy snapshot to test sub-account, run provisioning script, verify end-to-end
Day 21
Documentation + Handoff
  • Maintenance guide
  • System architecture doc
  • Loom walkthrough recorded
  • Workflow exports
  • All credentials documented
End of Phase 5: production ready

The system is live, tested, documented, and snapshot-ready. You can clone it to a new client sub-account in under 30 minutes. From here, the system runs without intervention.

Prerequisites

What we need from you before Day 1 to start building immediately.

  • 1
    GoHighLevel agency account (or sub-account access)
    We build inside a sub-account. Agency-level access lets us create and configure everything.
  • 2
    Credit repair offer details (pricing, community access, etc.)
    The AI needs to know what it is selling: pricing, packages, onboarding steps, and community access details.
  • 3
    Brand voice recording (60 seconds for ElevenLabs cloning) OR pick a preset voice
    A 60-second recording of you speaking naturally. We use this to create a voice clone for voice notes. Alternatively, pick from ElevenLabs preset voices.
  • 4
    Existing sales scripts or objection handling notes
    We build the playbook from these. The more you can share about your current sales process, the better the AI performs from Day 1.
  • 5
    Twilio account (or we set one up on Day 1)
    For voice note delivery via MMS. If you do not have one, we create it during Phase 1.
  • 6
    OpenAI or Anthropic API key (for the AI engine)
    The AI conversation engine runs on your API key. We configure it during setup.
  • 7
    Sample lead messages (5–10 real conversations to train and test against)
    Real conversation screenshots or exports. We use these to test and tune the AI's responses before going live.
Critical path

The AI brain quality depends on the sales playbook input. The more you can share about your current sales process — scripts, common objections, successful close techniques — the better the AI performs from Day 1.

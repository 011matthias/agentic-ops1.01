Conversation Flow

Step-by-step: from inbound message to delivered response. Every message follows the same pipeline regardless of channel.

1
Lead sends message via GHL
SMS, web chat, Facebook, or Instagram. Any channel connected to GHL.
2
GHL fires webhook to n8n
Webhook contains message content, contact ID, conversation ID, and channel type.
3
n8n loads conversation history from GHL API
Full conversation thread retrieved so the AI has complete context.
4
n8n sends message + history + prospect profile to AI engine
Includes: current message, full history, contact custom fields, pipeline stage, and tags.
5
AI engine consults: sales playbook, conversation state, objection library
Determines where in the sales flow this conversation is and what the next move should be.
6
AI generates response + decides medium
Output includes: text response, recommended medium (text, voice note, or multimedia), and any pipeline updates.
7
If voice note: text → ElevenLabs → audio → Twilio MMS
Text is converted to speech using the brand voice, hosted on CDN, and sent via Twilio MMS.
8
If multimedia: select asset from media library based on context
AI picks the right asset (testimonial, screenshot, infographic) based on what the prospect asked about.
9
n8n sends response via GHL Conversations API
Response delivered through the same channel the lead used (SMS, web chat, social).
10
n8n updates GHL: tags, custom fields, pipeline stage
Conversation state, lead temperature, and pipeline position are updated automatically.
11
Response delivered to lead via original channel
The lead receives the response where they messaged. The entire flow takes seconds.

Follow-Up Engine

Three behavior-based tracks. Each generates AI-personalized messages on a timed schedule. The AI adapts the message based on what it knows about the prospect.

Track 1: Ghost (No Response)
  • Day 1 Casual check-in (text)
  • Day 3 Value hook + voice note
  • Day 7 Direct close attempt
  • Day 14 Breakup message
Track 2: Clicked but Did Not Buy
  • Day 1 Address common objection
  • Day 3 Social proof (testimonial)
  • Day 5 Incentive (if applicable)
Track 3: Asked but Went Cold
  • Day 1 Pick up where they left off
  • Day 3 New angle based on their questions
  • Day 7 Direct close

Snapshot Flow

Two parts: creating the template (done once), and cloning to new clients (repeatable in under 30 minutes).

Part 1: Creating the Template

  • Build system in GHL sub-account
  • Create snapshot (captures: pipelines, tags, fields, workflows, templates)
  • Build provisioning script (handles: Twilio, ElevenLabs, n8n, AI config)
  • Test: deploy to test sub-account, verify end-to-end

Part 2: Cloning to New Client

  • Apply GHL snapshot to new sub-account (API call)
  • Run provisioning script with new client config
  • Customize sales playbook for new offer/niche
  • Send test message to verify
  • Go live
Under 30 minutes

Once the template exists, deploying to a new client takes under 30 minutes. The GHL snapshot handles the CRM config. The provisioning script handles the external stack. The only manual work is customizing the sales playbook for the new offer.

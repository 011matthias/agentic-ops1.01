Pricing Breakdown

Investment

Two phases: a fixed-price build that delivers all three agents, then an ongoing retainer for new workflows and optimization.

Pricing Overview

$2,400
Phase 1: Fixed price (3 weeks, all three agents)
EUR 2,000
Phase 2: Monthly retainer (20 hrs/week)

Phase 1 is scope-based: you pay for the deliverables, not for hours. Phase 2 is capacity-based: 20 hours per week of dedicated automation development, optimization, and maintenance.

What Phase 1 Includes

Deliverable Description
3 AI support agents Tier 0 auto-resolve, Tier 1 agent-assisted, Tier 2 engineering escalation
Classification engine Claude API with structured JSON output, confidence thresholds, category taxonomy
Tool integrations CRM, Slack, project management, knowledge base connections
Error handling Retry logic, dead letter queue, monitoring alerts
Documentation Runbook, API docs, architecture diagram
n8n workflow exports Importable JSON files for all agents
You own everything

All workflows export as JSON. All documentation lives in your systems. If we stop working together, you keep the full codebase and can maintain it independently.

What the Retainer Covers

  • New workflow development (2-3 per month)
  • Optimization and tuning (confidence calibration, response quality improvements)
  • Monitoring and maintenance (uptime, classification accuracy, alert response)
  • Knowledge base expansion (new patterns, templates, categories)
  • Ongoing support included (no time-limited windows, no separate support fees)

The retainer isn't just maintenance. Most of the monthly hours go toward building new automation capabilities on top of the existing system. As your team identifies new patterns, we add them to the classification engine. As your tools change, we update the integrations.

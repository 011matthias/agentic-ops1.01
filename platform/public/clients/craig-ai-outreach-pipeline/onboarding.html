What You Need

Four things to have ready before we start. If you need help with any of these, let us know during the kickoff call.

  • 🗃
    CRM Access
    Admin access or API key to your CRM (HubSpot, GoHighLevel, Pipedrive, etc.) with read permissions on contacts. We need to set up a webhook that fires when a lead is ready for outreach.
  • 📧
    Email Tool Account
    Instantly, Smartlead, or your SMTP server credentials. If you do not have an outreach email tool yet, we recommend Instantly ($30/month) for its warm-up features and deliverability.
  • 🧠
    Claude API Key
    Sign up at console.anthropic.com. We use Claude Sonnet for research and message generation. Typical cost: $15–30/month at 50–200 leads/week. We help you set this up if needed.
  • 🖥
    Railway Account
    For hosting n8n. Sign up at railway.app. Free tier works for testing. Production hosting costs ~$5–10/month. We configure everything during Phase 1.

CRM Configuration

We need one webhook from your CRM. Here is what it should send.

What data does the webhook need to send?
At minimum: lead name, company name, website URL, and email address. Optional but helpful: LinkedIn URL, company size, industry tag, any notes from your CRM.
What if my CRM does not support webhooks?
We set up a polling schedule instead. n8n checks your CRM every 15–60 minutes for new leads marked as “ready for outreach”. Slightly slower but works with any CRM that has an API.
Can I add leads manually?
Yes. We include a CSV upload option. Drop a spreadsheet into a shared folder and the pipeline picks it up.

Email Tool Setup

We connect to whichever email tool you use. No migration needed.

Recommendation

If you do not have an email outreach tool yet, we recommend Instantly ($30/month). Its warm-up feature helps new domains avoid spam filters. We can help you set it up during Phase 1.

What about LinkedIn?
LinkedIn’s API does not support direct message sending reliably. Two options: (1) Dripify Pro ($59/month) has webhook integration we can connect to, or (2) we queue LinkedIn messages as tasks in Google Sheets for you to send manually. Most clients start with option 2 and add Dripify later.

Claude API Setup

Claude API is the intelligence layer. Here is what to expect.

How much does Claude API cost?
At 50–200 leads per week, expect $15–30/month. Each lead requires roughly 2 API calls (one for research, one for message generation). We use Claude Sonnet which costs $3 per million input tokens.
Do I need to know how to use the API?
No. We configure everything. You just need the API key from your Anthropic account.

FAQ

Common Questions

Answers to the most common questions about the outreach pipeline project.

General

How is this different from tools like Instantly or Lemlist?

Instantly and Lemlist are email sending tools. They handle deliverability, warm-up, and scheduling. This system sits on top of those tools and handles the intelligence layer: researching each prospect, generating personalized messages, and managing the approval workflow. You still use Instantly (or whatever email tool you prefer) for the actual sending.

Can I use this with any CRM?

Yes. Any CRM with webhook support or an API works. HubSpot, GoHighLevel, Pipedrive, Close, even Airtable. If your CRM does not support webhooks natively, we set up polling instead (checks for new leads every 15–60 minutes).

How many leads can the system handle?

Practically unlimited. n8n processes leads sequentially but quickly (30–60 seconds per lead including Claude research). At 50 leads per day, the system runs comfortably. At 200+ per day, we add parallel processing. The Claude API is the only bottleneck, and it handles thousands of requests per minute.

Technical

What if Claude generates a bad message?

Every message goes through the approval queue. You see the draft alongside the research summary. Edit, rewrite, or reject. Nothing sends without your explicit approval.

What happens when a website cannot be scraped?

Some sites block automated scraping (Cloudflare protection, JavaScript-heavy SPAs). In those cases, the system falls back to the lead's company name and any CRM data available. The message will be less personalized but still better than a generic template. These leads are flagged in the dashboard so you know the research was limited.

Do I need technical skills to use this?

No. The approval queue and dashboard are simple interfaces. Approve a message with one click, track status in a Google Sheet. If you want to change the research prompt or adjust the relevance threshold, that requires editing a text field in n8n, which we walk you through during handover.

What about GDPR and data privacy?

All data stays on your infrastructure. n8n runs on your Railway server, not a shared platform. Prospect data is processed through Claude API (Anthropic does not use API data for training). No data is stored in third-party databases beyond your existing tools.

Pricing

Why $3,500 instead of the $15–100/hr range listed in the job?

Fixed price removes risk for both of us. You know the total cost upfront. I can invest the time needed to get the research prompts right without watching a clock. At $57/hr (the average bid), $3,500 represents about 61 hours — tight for this scope. Fixed price means I absorb overruns, not you.

What are the ongoing costs after delivery?

Railway hosting: $5–10/month. Claude API: $15–30/month at typical volumes (50–200 leads/week). Your email tool subscription (Instantly is $30/month). Total: roughly $50–70/month in tool costs. No ongoing fees to us unless you want optimization work ($75/hr).

Can we start with Phase 1 only?

Yes. Phase 1 ($2,000) delivers the core pipeline: CRM pull, Claude research, message generation, and approval queue. You can evaluate it with real leads before committing to Phase 2. Phase 2 adds email/LinkedIn delivery, tracking, and the dashboard.

After Delivery

What if I want to add more features later?

Ongoing work at $75/hr. Common additions: follow-up sequences, inbound lead handling, CRM write-back, multi-language outreach, A/B testing of message styles.

Can I modify the system myself?

Yes. n8n has a visual editor. Changing the research prompt or message template is editing a text field. Adding a new integration is dragging a new node. We provide a maintenance guide covering the most common changes.

What if something breaks?

The system includes error handling and Slack alerts. If an API call fails, you get a notification with details. Most issues are credential expirations (easy to fix) or API format changes (which we can address as a separate engagement).

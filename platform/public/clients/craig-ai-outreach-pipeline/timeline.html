DAY 2
Website Scraper

  • Error handling for unreachable sites
DAY 3

  • Design research prompt
  • Test with 10 real websites

DAY 4
Message Generation
  • Build generation prompt

DAYS 6–7

Prerequisites

Important

Timeline is conditional on these being ready on Day 1. Missing access can delay the project.

  • CRM access (admin or API key with contact read permissions)
  • Email tool account (Instantly, Smartlead, or SMTP credentials)
  • LinkedIn account (if LinkedIn outreach is in scope)
  • Claude API key (we help you set this up if needed)
  • Railway account (for n8n hosting, ~$5–10/month)

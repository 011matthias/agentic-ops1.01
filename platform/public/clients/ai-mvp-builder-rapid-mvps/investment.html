Custom build vs SaaS, the real comparison

This is the table that should drive the decision. I would rather you pick the cheaper SaaS option if it fits, because half-built custom tools waste everyone's money.

OptionSetupMonthlyBest whenWorst when
Custom (this proposal) $400 paid test + Phase 1+2 (hourly) OpenAI API + hosting only Data is messy, confidence scoring matters, want full ownership Data is mostly clean and a SaaS would work fine
Algolia Lower (mostly config) Plan-dependent Team likes their dashboard, data is mostly clean You need custom dedupe / confidence / triage before search
Pinecone or Weaviate Medium (you still build the app) Plan-dependent Want vector search but app glue is light Dedupe / normalization layer is still custom anyway
Self-hosted (Qdrant, Weaviate OSS) Higher (infra + ops) Infrastructure only Volume is large enough that SaaS pricing hurts Small team without ops capacity

Monthly costs vary by plan tier and change often. Check current pricing pages before deciding. I have linked the vendor sites so you can verify directly.

What is included at every price

  • Working code: structured Python, type hints, error handling on real-world data conditions
  • Tests: unit tests on the normalize and dedupe functions, integration test for the end-to-end pipeline
  • Documentation: how it works, where each script lives, how to swap models or vector stores
  • Handoff: walkthrough session plus a written handoff so the next engineer can maintain it
Why no fixed-price MVP quote

Software estimates that try to be precise on messy-data projects almost always miss. The paid test gives both of us real numbers to base the MVP estimate on. After Phase 0, the MVP estimate gets tightened with actual data in hand.

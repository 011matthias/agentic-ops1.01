Delivery Approach

The project is structured as four sequential phases. Each phase is independently valuable - meaning you get a working, useful system at the end of each one, not just at the end of the whole project. If priorities shift after Phase 1 or 2, the work already done has standalone value.

There is a review checkpoint between each phase. We review what was built, confirm it is working as expected, and agree on scope before starting the next phase. This prevents scope drift and keeps the project aligned with your actual priorities as they evolve.

Estimates are working estimates

The durations below are based on similar projects. They will be refined once the platform decision is made (n8n, Firebase/Firestore, or custom) and the open investigation items on the Overview page are resolved.

Phases

P1
Phase 1 - Foundation 2-3 weeks

Get leads flowing. SAP channel and website form ingest, basic normalization, and logging to your destination. No scoring or AI yet - just reliable, automated capture with a consistent data format.

  • n8n instance setup and environment configuration
  • A2: SAP Discovery Center and SAP Store email ingest
  • A1: Website form ingest via webhook
  • Normalized lead schema and destination logging (Sheets, CRM, or n8n DB)
  • Deduplication logic (same contact, same source, within N days)
  • Basic error alerting (ingest failures notify by email)
Deliverables: 2 working ingest workflows (A1, A2), lead destination configured and receiving data, error alerting active, handover documentation.
Review checkpoint - confirm Phase 1 is working, agree on Phase 2 scope
P2
Phase 2 - Intelligence 2-3 weeks

Add scoring, AI response drafting, and the human review gate. This is when the pipeline starts saving significant time - high-value leads get drafted responses automatically, routing logic keeps the right leads in front of a human.

  • Lead scoring logic (signals, weights, tier assignment)
  • AI response drafting (GPT-4o-mini with channel-specific templates)
  • HITL review gate - High tier held for approval, Medium/Low auto-send
  • Review notification (email or Slack) with approve/edit/reject flow
  • A0: LinkedIn ingest (if confirmed as active channel during Phase 1)
  • Scoring threshold tuning based on real lead data from Phase 1
Deliverables: Scoring logic live and tunable, AI drafting operational, HITL review workflow active, LinkedIn ingest (conditional), updated documentation.
Review checkpoint - confirm scoring thresholds, review sample AI drafts, agree on Phase 3 scope
P3
Phase 3 - Reply Monitoring 1-2 weeks

Close the loop. Once a first response has been sent, A4 monitors for replies. When a lead responds, the follow-up sequence stops and the reply is surfaced to a human reviewer with full context. No second message is ever automated.

  • A4: Inbox polling and thread ID matching
  • Follow-up sequence cancellation on reply detected
  • Human escalation notification with full context package
  • SLA tracking (optional - flag leads that have not received a first response within X hours)
  • End-to-end testing across all channels
Deliverables: Reply monitoring live (A4), escalation workflow active, optional SLA alerting, full end-to-end test report, final documentation.
Full system live - post-launch support period begins (2 weeks per phase)
P4
Phase 4 - Platform Extension Ongoing

Once lead nurturing is running, the same platform extends to handle other business workflows. Each is a new "channel" using the same architecture: ingest, process, approve, send, track.

  • Invoice / AP routing - auto-forward invoices to expense owners for approval, track payment status, reconcile with credit card statements
  • Compliance email management - channel compliance-related emails through the tool, AI-assisted drafting, monitoring and follow-up
  • LinkedIn message management - all LinkedIn messages visible in dashboard, response drafting assistance, conversation tracking
  • Multi-tenant enablement - same platform supporting multiple Dirk entities (Brisken + others), isolated data per tenant
  • Additional channels - any new email-based or messaging-based workflow added without rebuilding the core
Note: Each extension uses the same platform and dashboard. Scoped individually as the lead pipeline stabilizes. Priority order to be determined based on business impact.

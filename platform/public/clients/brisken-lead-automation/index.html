The Challenge

Brisken receives leads from multiple channels: SAP Discovery Center, SAP Store, website forms, and LinkedIn. Each channel delivers leads differently, and each has different signal quality. With roughly 10 leads per week, the volume is low but each lead matters. The bottleneck is not filtering out noise; it is making sure every lead gets a fast, personalized, high-quality response and consistent follow-up.

Beyond lead nurturing, the same operational challenge shows up elsewhere: invoice routing requires manual email forwarding every day, compliance emails need tracking, and LinkedIn conversations happen in a separate silo. Multiple tools, multiple inboxes, no central place to manage it all.

The goal is a unified platform that handles all of this from one place. Automated processing handles the repeatable work. Human judgment stays in the loop for approvals, high-value leads, and all follow-up responses. One dashboard to manage leads, invoices, compliance, and communications across every channel.

What We're Building

A unified automation platform with lead nurturing as the first use case, designed from day one to extend into invoice routing, compliance tracking, and general email management. All managed from a single dashboard.

  • Unified dashboard - one place for all channels, all approvals, all conversation history. No switching between LinkedIn, Outlook, and CRM
  • Multi-channel lead capture - SAP Discovery Center, SAP Store, website forms, and LinkedIn all flow into the same pipeline
  • 4-tier classification - each lead is scored and classified as SPAM, Low, Medium, or High. Spam is filtered out; all others get a response. Configurable weight table, not hardcoded
  • AI response drafting - personalized first responses acknowledging the lead's specific interest, sent from Dirk's personal email via SMTP
  • Human review gates - high-value leads held for approval before sending. All second responses (replies) go through mandatory human review, regardless of lead tier
  • Automated follow-up sequences - in-thread follow-ups for unresponsive leads, always individually crafted, with approval gates
  • CRM abstraction - standard event layer (Create Lead, Add Comment, Update Status) with Zoho as the first connector. Swap CRM later without reworking logic
  • Extensible architecture - same platform handles invoice/AP routing, compliance emails, and LinkedIn message management as future use cases

How each channel flows through the system

Every channel follows the same core pipeline, but the intake method and context extraction differ. Here is the journey for each source, from arrival to response.

SAP Store Lead
Email arrives → A2 polls inbox → Extract product + contact → Classify (+5 channel) → AI draft (product-aware) → HITL review → Send via SMTP
SAP Discovery Center Lead
Email arrives → A2 polls inbox → Extract use case + contact → Classify (+1 channel) → AI draft (UC-aware) → Route by tier → Send via SMTP
Website Form Lead
Form submitted → A1 webhook fires → Extract category + landing page → Classify → AI draft → Route by tier → Send via SMTP
LinkedIn Lead (pending validation)
Message or form → A0 API read or manual → Extract campaign context → Classify → AI draft → Route by tier → Send or manual paste

Open Investigation Items

These are items from our scoping discussion that need further research before finalizing the architecture. Each one will be evaluated and reported back with a recommendation.

Item What We Need to Determine Status
Platform choice Evaluate n8n vs Firebase/Cloud Firestore vs custom code. Trade-offs: development speed, dashboard capabilities, multi-tenant readiness, ongoing cost. Evaluating
SMTP email sending Confirm SMTP connection to Dirk's corporate email works from the chosen platform. Verify the automation can send as Dirk without requiring inbox access. Evaluating
LinkedIn API restrictions Check whether outbound messaging via API risks account flagging or suspension. If restricted, design a manual-send fallback (pre-drafted messages, copy-paste workflow). Evaluating
Reply capture architecture Current plan: Outlook auto-forward to a monitored mailbox. Investigating whether a more elegant solution exists that avoids the middleman pattern, especially for multi-reply threads. Evaluating
Hosting approach Cloud-hosted vs self-hosted for the chosen platform. Factors: data sovereignty, cost at current volume, maintenance burden, scaling path. Evaluating
Multi-thread edge cases How to handle concurrent replies from the same lead (e.g., "not interested" in one thread, "tell me more" in another). Need a conflict resolution strategy. Design phase
Email reputation safeguards Research blacklist risk for the planned follow-up cadence. Define maximum follow-up frequency and opt-out detection to protect Brisken's sender reputation. Design phase
Website form integration Determine form tool (Wix, Tally, custom) and whether it supports webhook endpoints or direct database connection. Either path works; need to confirm which. Needs input
Zoho CRM configuration Confirm Zoho can handle automated event writes at the needed granularity (lead created, email sent, reply received, lead closed). Map fields and determine API approach. Needs input

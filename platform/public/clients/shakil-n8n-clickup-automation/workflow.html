SEO Monitoring Workflow

A Ready-to-Import n8n Workflow for Shakil's Sites

This page walks through the SEO monitoring workflow step by step, shows how the data flows between systems, and lets you download the n8n JSON to import directly into your instance.

How the SEO Monitoring Workflow Works

The workflow runs on a daily schedule. It pulls rank data and backlink health for each of your three properties, consolidates the results, and either updates your Google Sheets dashboard or creates a ClickUp alert if something drops. No manual intervention unless a threshold is crossed.

1
Scheduled trigger (daily)

The workflow fires automatically each morning. You can adjust the time and frequency in the n8n Schedule node. No cron syntax needed.

2
Google Search Console API pull

For each site (sipraw.com, trendRox.com, UK real estate), the workflow calls the Search Console API to fetch keyword positions over the past 7 days. Results are stored as structured objects in memory.

3
Rank data processing

Previous day's positions are compared against today's. Keywords that moved more than the configured threshold (default: 5 positions) get flagged. The delta is computed per keyword, per site.

4
Backlink check via Ahrefs or SEMrush API

A separate branch calls either Ahrefs or SEMrush (whichever Shakil has access to) to check for new lost links and any domains flagged as toxic. This runs in parallel with the rank check to keep the workflow fast.

5
Data consolidation

All three sites' rank data and backlink results are merged into a single structured payload. This is the object that gets written to the dashboard and evaluated for alerts.

6
Dashboard update (Google Sheets)

The consolidated data writes to a Google Sheet with one tab per site. Rows are appended, not overwritten, so you keep a full history. Column headers are set up in the template sheet included in the download.

7
Alert triggers

If any keyword dropped more than 5 positions (or whatever threshold is configured), the workflow creates a ClickUp task in your SEO list and optionally sends an email notification. No drop means no noise.

What this replaces

Three freelancers sending three separate weekly reports in whatever format they prefer. Instead, you get a single dashboard updated every morning, and a ClickUp task only when something actually needs your attention.

Credentials you'll need

  • Google Search Console API (OAuth, one per Google account that manages the properties)
  • Ahrefs or SEMrush API key (the workflow has a toggle node to switch between them)
  • Google Sheets API (via the same Google OAuth connection)
  • ClickUp API token (from your ClickUp settings)
n8n credential note

n8n stores credentials encrypted in its database. You set them up once in the Credentials panel, then the workflow references them by name. Nothing is stored in the workflow JSON itself, so the download is safe to share.

How to import into n8n

  1. Open your n8n instance and go to Workflows in the left sidebar.
  2. Click Import from file (or drag the JSON file onto the canvas).
  3. Open the "Config" node at the top of the workflow and fill in your Sheet ID, ClickUp list ID, and alert threshold.
  4. Connect your Google, Ahrefs/SEMrush, and ClickUp credentials in the relevant nodes.
  5. Run a manual test with the Execute Workflow button to verify the first data pull.
  6. Activate the workflow. The schedule takes over from there.

What You Can Customize

The workflow is built so Shakil can adjust it without touching the core logic. All configurable values are in a single "Config" node at the start of the workflow. Here's what's exposed:

Setting Default What it controls
Sites to monitor sipraw.com, trendRox.com, uk-realestate.com Add or remove URLs. Each site runs through its own sub-workflow branch.
Alert threshold 5 positions Change to 3 for more sensitivity or 10 for fewer alerts. Applied per keyword, per site.
Run frequency Daily at 07:00 Switch to weekly for lower API usage, or on-demand by triggering the webhook node manually.
Dashboard format Google Sheets The output node can be swapped to Airtable or a ClickUp doc with a small config change. Both variants are commented out in the workflow.
Alert channel ClickUp task + email Disable either channel independently. Add a Slack node if that's where your team works.
Backlink provider Ahrefs Toggle to SEMrush in the Config node. Both credential slots are present; activate the one you use.
No code changes needed for customization

All of the above are controlled by the Config node, not by editing expressions inside individual nodes. If you want to change something not listed here, that's a quick addition and I can walk you through it on the onboarding call.

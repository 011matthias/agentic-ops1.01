Timeline

A phased approach. Each phase delivers working automation you can test before moving to the next.

Phase 1 — Audit and Foundation

Week 1-2 First working pipeline live by end of week 2

Before writing any automation, we need to understand what you've already got and where it breaks down. This phase ends with something real running, not a deck of recommendations.

1
Stack audit
Map your current tools (Apollo, HeyReach, LinkedIn, CRM) and how data flows between them today. Where do leads arrive manually? Where do they fall out? Which steps happen in spreadsheets?
2
Gap analysis
Identify where manual steps exist and which connections between tools are missing. This produces a ranked list of automation opportunities sorted by time saved per week.
3
Pipeline design
Design the Make.com and n8n architecture for your specific stack. Which tool handles which stage, where the data lives, and how each integration connects. You review and confirm before any build starts.
4
First pipeline live
Build and deploy the lead capture pipeline for your highest-volume source. If that's HeyReach/LinkedIn, that's what goes first. If it's Apollo prospecting lists, we start there. Real leads flowing through real automation by end of week 2.
Phase 1 ends with a working pipeline

Not a document, not a plan. A live automation you can test with real leads. Every phase after this builds on something that's already running.

Phase 2 — Outbound and Scoring

Week 3-4 Lead scoring and outbound sequences live

With capture running, Phase 2 adds the intelligence layer. Leads stop being a flat list and start being a scored, routed pipeline.

1
Outbound workflows
Build cold email and LinkedIn outreach sequences in n8n. Configurable timing, reply detection to stop sequences automatically, and event logging so you can see what's working.
2
Lead scoring model
Deploy the scoring algorithm with thresholds calibrated to your ICP. The initial weights are a starting point based on typical B2B signals. After two weeks of data, we'll tune them to your actual conversion patterns.
3
CRM integration
Connect the pipeline to your CRM with bidirectional sync. Lead scores, source channels, sequence history, and enrichment data all land in the right fields. No manual data entry.
4
Reporting setup
Google Sheets dashboard with conversion funnel by source, sequence open and reply rates, and weekly summaries. The data is already being logged from Phase 1, so this is mostly about surfacing it clearly.

Phase 3 — Optimization and Scale

Week 5-8 Full pipeline running across all channels

By Phase 3, you have four weeks of real conversion data. That's enough to make the scoring model accurate rather than assumed.

1
Performance tuning
Adjust scoring weights based on actual conversion data. Which signals actually predict a reply or a meeting booked? The model gets recalibrated against your real results, not generic B2B benchmarks.
2
New source integration
Add remaining channels to the capture pipeline (Reddit monitoring, additional ad platforms, any other sources from the Phase 1 gap analysis that weren't in the first wave).
3
A/B testing infrastructure
Automated split testing for email sequences. n8n routes leads to variant A or variant B, tracks outcomes per variant, and the reporting dashboard shows which performs better. No manual tracking needed.
4
Alerting and monitoring
Anomaly detection for pipeline health. If lead volume drops by more than 30% week-over-week, or if error rates spike on any integration, you get a Slack alert before it becomes a problem you notice manually.

Ongoing

Post Phase 3 Monthly retainer

After Phase 3, the pipeline is built and running. The ongoing retainer covers keeping it working, extending it as your stack changes, and refining it as you learn more about what converts.

Pipeline monitoring
Regular health checks on all integrations. Errors get caught and fixed before they affect lead flow. You don't have to watch the automations yourself.
New source integrations
As your marketing stack evolves, new channels get wired into the pipeline. Each new source follows the same capture-normalize-enrich-score-route pattern so it's not starting from scratch.
Scoring model refinement
Quarterly reviews of the scoring weights against conversion data. The model should get more accurate over time, not stay frozen at the week-5 calibration.
Ad hoc automation requests
One-off workflows that come up as your processes change. New sequences, integrations with tools you add to the stack, reporting changes, or anything that's currently being done manually.
Phases are flexible

If you want to start with outbound automation instead of lead capture, we can reorder. If there's a specific bottleneck you're feeling right now, that's where we start. The phases above are the default sequence, not a fixed contract.

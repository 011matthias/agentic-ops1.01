Week 1: CRM Setup & First Workflow

Phase 1 — Week 1
Zoho CRM configured and first automation live
  • ✓ Zoho CRM configuration: patient profiles, deal pipeline stages, package fields (Basic / Plus / Complete), physician assignment
  • ✓ CRM dashboard: patient pipeline view covering intake, testing, treatment, and aftercare stages
  • ✓ n8n instance setup and connection to Zoho CRM
  • ✓ First workflow deployed: Patient Intake — form submission creates CRM record and triggers confirmation email
Deliverable: Working intake workflow, CRM configured and populated with test data

Week 2: Booking & Payment Integration

Phase 1 — Week 2
End-to-end booking and payment flow live
  • ✓ Cal.com setup: appointment types (intro call, follow-up, monitoring), automatic Google Meet link generation
  • ✓ Mollie integration: deposit payments, package payments, subscription handling
  • ✓ Payment confirmation workflow: updates CRM, notifies physician, triggers next sequence
  • ✓ Brevo email setup: confirmation templates and appointment reminder templates
  • ✓ MessageBird SMS setup: appointment reminders configured and tested
Deliverable: End-to-end booking and payment flow working from first click to CRM update

Week 3: Communication Build-Out

Phase 1 — Week 3
All email and SMS sequences built and tested
  • ✓ Welcome and confirmation email after intake
  • ✓ Appointment reminders: 24h, 6h, and 1h before
  • ✓ Blood kit dispatch notification with track-and-trace link
  • ✓ Lab receipt confirmation
  • ✓ Treatment plan invitation
  • ✓ Monitoring appointment scheduling sequence
  • ✓ Aftercare check-ins at month 1, 3, 6, and 12
  • ✓ SMS sequences in MessageBird for all time-sensitive reminders
  • ✓ All content written in Dutch using Menovia's existing drafts
Deliverable: All communication templates live and tested end to end

Week 4: End-to-End Testing

Phase 1 — Week 4
Full patient journey validated and production-ready
  • ✓ Complete patient journey test: intake through to aftercare
  • ✓ Edge case handling: missed payments, cancelled appointments, expired consents
  • ✓ CRM dashboard review session with the Menovia team
  • ✓ Performance verification: all workflows trigger correctly and all notifications fire on schedule
Deliverable: Fully tested system ready for production
Phase 2 begins

Weeks 5–7 cover GDPR compliance, Intercom, Dutch content finalisation, and full handover. Phase 2 can be added at any point after Phase 1.

Week 5: GDPR Compliance Audit

Phase 2 — Week 5
Every data flow verified against GDPR requirements
  • ✓ Verify EU data hosting for every connected tool in the stack
  • ✓ Consent flow verification: every data collection point records explicit consent
  • ✓ Data retention policy configuration across all tools
  • ✓ DPA documentation: which agreements are in place and what they cover
Deliverable: GDPR compliance report and consent flows verified

Week 6: Intercom & Content

Phase 2 — Week 6
Intercom live, Dutch content finalised across all channels
  • ✓ Intercom EU workspace setup and configured
  • ✓ CRM integration: website visitors matched to patient records
  • ✓ FAQ bot configuration for common patient questions
  • ✓ Dutch content finalised across all email and SMS templates
  • ✓ EHR integration assessment: recommendations for connecting to NEN 7510-certified system
Deliverable: Intercom live, all content finalised, EHR recommendations documented

Week 7: Documentation & Handover

Phase 2 — Week 7
Everything handed over, team trained, system fully owned by Menovia
  • ✓ Full technical documentation: system overview, workflow descriptions, troubleshooting guide
  • ✓ User guide for the Menovia team: how to monitor, adjust, and extend the system
  • ✓ Team training session (video call, recorded for future reference)
  • ✓ Handover package: credentials, documentation, n8n access, CRM admin
  • ✓ Post-launch support begins
Deliverable: Complete handover, team trained, documentation delivered, support period active

Workflow Overview

This template demonstrates the core patient intake automation. When a new patient submits their details through your website form, this workflow handles everything that follows automatically.

What This Workflow Does

  • Receives patient form submissions via a live webhook endpoint
  • Validates that all required fields are present (name, email, GDPR consent)
  • Logs GDPR consent with a timestamp and source for compliance records
  • Creates a new contact in your CRM with the correct pipeline stage
  • Sends a personalised confirmation email in Dutch
  • Schedules a booking reminder for patients who have not booked within 24 hours

Node-by-Node Walkthrough

The workflow consists of 8 nodes arranged in a linear flow with one validation branch. Here is what each node does and why it matters.

1
Patient Form Submission
Webhook Trigger
Listens for POST requests at /webhook/menovia-intake. This is the entry point: when a patient submits your website form, their data arrives here as a JSON payload containing name, email, phone, selected package, and GDPR consent status.
2
Validate Required Fields
IF Node
Checks three conditions before proceeding: email is not empty, name is not empty, and GDPR consent is true. If any check fails, the workflow branches to return a 400 error response. This prevents incomplete records from entering your CRM.
3
Log GDPR Consent
Set Node
Records the consent timestamp (ISO 8601), consent source ("intake_form"), and consent version ("1.0") alongside the patient's details. This structured consent log is what makes the workflow GDPR-auditable. Every record can trace exactly when and how consent was given.
4
Create CRM Contact
HTTP Request (Zoho CRM)
Creates a new contact in Zoho CRM via the EU API endpoint (zohoapis.eu). The contact record includes first name, last name, email, phone, lead source, selected package, and the GDPR consent details in the description field. Lead status is set to "New".
5
Send Confirmation Email
Email Send (Brevo)
Sends a personalised confirmation email in Dutch to the patient. The email confirms their submission, states their selected package, and tells them to expect a booking invitation. Reply-to is set to contact@menovia.nl.
6
Schedule Booking Reminder
Set Node
Prepares a reminder record for patients who have not booked within 24 hours. In production, this connects to a scheduled workflow that checks whether the patient booked and sends a follow-up if they have not.
7
Success Response
Respond to Webhook
Returns a JSON success response to the form: {"status": "success", "message": "Bedankt voor uw aanmelding."}. Your website form can display this confirmation to the patient.
!
Validation Error
Respond to Webhook (400)
Branches from the IF node when validation fails. Returns a 400 error with a Dutch message: "Verplichte velden ontbreken of toestemming is niet gegeven." This tells the form to prompt the patient to complete all required fields.

Try It Live

This workflow is deployed and running on n8n Cloud right now. You can test it by sending a POST request to the webhook endpoint below.

Webhook Endpoint

URL 
https://unpauseai.app.n8n.cloud/webhook/menovia-intake

Sample Request

cURL 
curl -X POST https://unpauseai.app.n8n.cloud/webhook/menovia-intake \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Maria de Vries",
    "email": "maria@example.com",
    "phone": "+31612345678",
    "package": "Plus",
    "gdpr_consent": true
  }'

Reference Guide

Detailed technical information for each area of the project. Review these before or during the kickoff call, or use them as reference later. All sections are optional reading.

For each tool, we need specific credentials or API keys. Share all credentials securely via your preferred method (password manager link, encrypted email).

Zoho CRM
We need: Admin API credentials (Client ID, Client Secret, Refresh Token)
  1. Go to api-console.zoho.eu
  2. Click Add Client and select Self Client
  3. Enter the scope: ZohoCRM.modules.ALL
  4. Generate the authorization code and exchange it for a refresh token
  5. Share the Client ID, Client Secret, and Refresh Token securely
Brevo
We need: SMTP credentials + API key
  1. Go to app.brevo.com
  2. Navigate to Settings → SMTP & API
  3. Click Generate a new API key
  4. Copy the API key (it is only shown once)
  5. Share the API key and SMTP credentials (server, port, login, password)
Cal.com
We need: API key + event type ID
  1. Go to app.cal.com/settings/developer/api-keys
  2. Click Create new key
  3. Copy the API key
  4. Also share the URL of the event type you want patients to book (e.g., cal.com/menovia/intake)
Typeform or Tally
We need: Form webhook URL or API key
  1. Create your intake form (we can help design the questions)
  2. Go to Connect → Webhooks
  3. Share the webhook URL with us
  4. Alternatively, share an API key so we can pull submissions directly
Intercom
We need: App ID + API token
  1. Go to app.intercom.com
  2. Navigate to Settings → Developers
  3. Create a new app or use existing credentials
  4. Share the App ID and API token
  5. Important: Requires EU workspace setup (we will verify during onboarding)
Mollie
We need: API key (test + live)
  1. Go to my.mollie.com
  2. Navigate to Developers → API keys
  3. Copy both the Test API key and the Live API key
  4. Share both keys securely
MessageBird
We need: API key + originator number
  1. Go to dashboard.messagebird.com
  2. Navigate to Developers → API access
  3. Click Create new key
  4. Also share the originator phone number (the number SMS will be sent from)
DNS / Domain verification

We will need to verify your sending domain in Brevo for email deliverability. This requires adding DNS records (SPF, DKIM, DMARC) to menovia.nl. We provide the exact records during onboarding.

Email templates needed

All patient-facing content should be in Dutch. We can draft templates based on your existing communications:

  • Booking confirmation — sent immediately after a patient books
  • Booking reminder — sent 24 hours before the appointment
  • Payment link — deposit request after intake is confirmed
  • Appointment reminders — series at 24h, 6h, and 1h before treatment
  • Blood kit tracking — status updates on blood test kit delivery and results
  • Treatment plan — post-consultation summary with next steps
  • Aftercare check-ins — automated follow-ups at 1 week, 1 month, 3 months

SMS content

Short appointment reminders via MessageBird at 24h, 6h, and 1h before.

Brand assets

  • Logo — SVG or high-resolution PNG (transparent background preferred)
  • Brand colors — primary and secondary hex codes
  • Tone of voice — any guidelines or examples of how you communicate with patients

Screening form questions

Share the list of patient intake questions (eligibility and lifestyle, not clinical assessments). Examples: age, gender, current medications, known allergies, previous treatments, treatment goals.

CRM pipeline stages

  1. Intake — new patient inquiry received
  2. Booked — consultation appointment scheduled
  3. Testing — blood work or diagnostic tests in progress
  4. Active Treatment — patient is undergoing treatment
  5. Aftercare — post-treatment follow-up and monitoring

FAQ

Common questions about the project, the tools, and how things work.

HubSpot and Plan Requirements

Do I need to upgrade my HubSpot plan?

It depends on what you're on now. HubSpot Professional and Enterprise support webhooks, which means n8n gets notified instantly when a deal moves to "Won" or a form is submitted.

If you're on HubSpot Starter or Free, webhooks aren't available. But n8n can poll the HubSpot API on a schedule (every 5 minutes, for example) and pick up new events that way. It's slightly less real-time but works fine for most use cases.

I'll check your plan during the review phase and recommend the best approach for your setup.

Can HubSpot's built-in workflows do this instead of n8n?

Partially. HubSpot workflows can trigger on deal stage changes and form submissions, but they don't have a native Xero integration. You'd need a third-party connector like Zapier or a custom API integration, which adds cost and complexity.

For the Google Drive folder creation, HubSpot would need Operations Hub (an additional paid tier) to make API calls to Google Drive.

Since you already have n8n self-hosted, building both automations there keeps everything in one place with no additional monthly costs per operation.

The Automations

How do the 3 pricing options work in the invoice automation?

You've got a custom field in HubSpot that determines which pricing tier applies to each deal. When a deal moves to "Won", n8n reads that field and routes to the correct invoice template.

Each tier has its own predefined line items, descriptions, and unit prices configured in the workflow. If the custom field is a dropdown with clean values (e.g., "Tier 1", "Tier 2", "Tier 3"), the mapping is direct. If it's a free text field, the workflow validates the input before proceeding.

Adding a 4th pricing tier later is a small change: one new route in the mapping node and the corresponding Xero line items.

What happens if a contact doesn't exist in Xero?

The workflow checks Xero for the contact by email before creating an invoice. If they don't exist, it creates a new Xero contact automatically using the name, email, and company from the HubSpot deal.

If you'd prefer to review new contacts manually before sending invoices, I can configure it to flag those deals instead of auto-creating. That's a decision we can make during the review phase.

What if an automation fails?

Both workflows have error handling built in. The main failure scenarios and how they're handled:

  • Invalid pricing field: The deal gets flagged in HubSpot with a note explaining the issue. No invoice is created.
  • Xero auth failure: Retries once. If it fails again, sends a notification so you can check the API connection.
  • Missing contact email: Skips invoice creation, logs a warning on the deal.
  • Duplicate submission: Checks if a folder or invoice already exists before creating a new one.
  • Google Drive permission issue: Validates access before attempting folder creation. Logs the error if it fails.

n8n also has built-in execution logging, so you can see every run, what happened, and where it stopped if something goes wrong.

What naming convention do the Google Drive folders use?

The default convention is: CompanyName - ContactName - YYYY-MM-DD

This makes folders sortable by company and date. If you prefer a different convention (e.g., project-based naming, sequential numbering), we can adjust that during the build phase.

Each folder also gets standard subfolders: Assets, Deliverables, and Correspondence.

Working Together

Will you fix my existing n8n setup or rebuild from scratch?

That depends on what I find during the review. If the structure of your mock-ups is sound and the logic is heading in the right direction, I'll refine and fix what's there. No point rebuilding something that's already close.

If the mock-ups have structural issues (wrong trigger type, missing error handling, tangled logic), it's usually faster and more reliable to rebuild cleanly. Either way, you get a working result by Day 5.

I'll give you an honest recommendation after the review. If rebuilding is easier, I'll explain why.

What access do you need?
  • n8n instance: Access to your self-hosted n8n (URL + login, or an API key)
  • HubSpot: API key or private app credentials with deals, contacts, and forms scopes
  • Xero: OAuth app connection (I'll walk you through the setup if needed)
  • Google Drive: Service account or OAuth access to the target folder

I'll send specific instructions during the onboarding step. Credentials are used only for the build and aren't stored after handoff.

Can I add more automations later?

Yes. Once these two are running, common follow-ups include:

  • Sending a welcome email when a deal is won (in addition to the invoice)
  • Creating a project in a task management tool when a form comes in
  • Syncing HubSpot contacts to Xero on a schedule (not just at deal close)
  • Adding Slack or email notifications for specific deal stages

Each of these builds on the same n8n setup. Follow-up work is billed at the same rate.

Build

Days 2-3
Implementation

Based on the recommendation, I either refine the existing workflows or build both automations from scratch on your n8n instance.

Automation 1 (Invoice): HubSpot deal trigger, pricing tier mapping for all 3 options, Xero contact lookup/creation, invoice generation and sending, deal note logging. Error handling for invalid fields, missing contacts, and auth failures.

Automation 2 (Folder): HubSpot form trigger, Google Drive folder creation with naming convention, subfolder setup, contact record update with folder URL. Duplicate detection for repeat submissions.

Both workflows get tested with sample data during this phase. I'll share screenshots and test results as I go.

Deliverables

  • Working Automation 2: Form Submission to Google Drive Folder

  • Sample data test results shared for review

Test and Handoff

Verification

Both automations are yours to manage. You've got the documentation, the walkthrough recording, and full access to the n8n workflows on your own server.

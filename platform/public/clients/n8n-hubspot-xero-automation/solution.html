Automation 1: Deal Won to Xero Invoice

What It Does

When a deal in HubSpot is marked as "Won", n8n automatically creates and sends an invoice through Xero. The invoice amount and line items are determined by a custom field in HubSpot that maps to one of three pricing options.

HubSpot CRM Xero Accounting n8n

How It Works

Trigger
HubSpot deal stage change webhook. If your HubSpot plan doesn't support webhooks, n8n polls the deals API on a schedule instead.
Field Extraction
Reads deal amount, associated contact email, company name, and the custom pricing field that determines which of the 3 pricing tiers applies.
Pricing Mapping
Looks up the custom field value and maps it to the correct Xero line items. If the field is a dropdown, the mapping is direct. If it's a text field, validation runs first to catch typos or unexpected values.
Contact Matching
Searches Xero for the contact by email. If they exist, uses the existing record. If not, creates a new Xero contact with the details from HubSpot before generating the invoice.
Invoice Creation
Builds the invoice in Xero with the correct line items, amounts, tax settings, and due date. Sends it to the contact automatically.
Logging
Writes the Xero invoice reference back to the HubSpot deal as a note, so your team can see the invoice was sent without switching to Xero.

Error Handling

  • Invalid or empty pricing field: flags the deal in HubSpot and sends a notification instead of creating a broken invoice
  • Xero auth failure: retries once, then notifies. Never silently drops an invoice
  • Duplicate detection: checks if an invoice already exists for this deal before creating a new one
  • Missing contact email: skips invoice creation and logs a warning so your team can fix the deal record

Automation 2: Form Submission to Google Drive Folder

What It Does

When someone submits a form on the client's website (built with HubSpot Forms), n8n creates a new folder in Google Drive and links it back to the contact record in HubSpot.

HubSpot Forms Google Drive n8n

How It Works

Trigger
HubSpot form submission webhook fires when a new form entry comes in.
Data Extraction
Pulls the contact name, email, company (if provided), and any custom fields from the form submission.
Folder Creation
Creates a new folder in a designated parent directory in Google Drive. Naming convention follows a pattern like "CompanyName - ContactName - Date" for easy sorting.
Subfolders
Optionally creates subfolders within the new folder (e.g., "Assets", "Deliverables", "Correspondence") so the workspace is organized from the start.
Contact Update
Writes the Google Drive folder URL back to a custom property on the HubSpot contact, making it accessible from the CRM without searching Drive manually.

Error Handling

  • Duplicate form submissions: checks if a folder already exists for this contact before creating a new one
  • Google Drive permissions: validates access to the parent folder before attempting creation
  • Missing required fields: if the form submission is missing key data (no name, no email), logs a warning and skips folder creation

Why n8n

You've already got n8n self-hosted, which is the right tool for this. Here's why it makes sense to stay with it rather than switching to HubSpot's built-in workflows:

  • Xero integration: HubSpot doesn't have a native Xero integration. n8n connects to the Xero API directly with full control over invoice fields, tax handling, and contact matching.
  • Custom pricing logic: HubSpot workflows can read custom fields but can't do conditional invoice generation with 3 pricing tiers. n8n handles this with a simple routing node.
  • No per-operation costs: Self-hosted n8n has no execution limits. These automations can run thousands of times without additional cost.
  • Custom code when needed: If the pricing mapping logic gets complex (e.g., discounts, volume pricing, currency conversion), n8n's code node handles it without workarounds.
  • Your data stays on your server: Self-hosted means deal data and invoice details never pass through a third-party automation platform.

FAQ

Frequently Asked Questions

Common questions about the email compliance monitor and AI chat system.

General

What exactly will I get at the end of this project?

Two production systems (email monitor + AI chat), GDPR documentation package (DPIA, transfer docs, retention policies), architecture docs, admin runbook, and a system that runs without developer involvement.

Why two phases?

Phase 1 delivers the email monitoring system (the "key component" from the brief) first. This means you see value in 3 weeks, not 5. Phase 2 adds the AI chat interface once the core system is proven.

Can we start with just Phase 1?

Yes. Phase 1 stands alone as a complete email compliance monitoring system. Phase 2 can be scoped separately whenever you're ready.

Technical

What happens if the email volume spikes?

The system uses queue-based processing (SQS/EventBridge), not direct API calls. Emails queue up and process at a controlled rate. CloudWatch alerts notify you if the queue depth exceeds normal thresholds.

How does the AI classify emails?

Each email goes through Anthropic's Claude API with a structured prompt that extracts sentiment, complaint detection, key tags (complaint, urgent, legal risk, escalation, cancellation), and a severity score (1-5). The prompt is tuned for your specific email patterns.

Can we add custom categories later?

Yes. The classification prompt is configurable -- adding new categories or adjusting severity thresholds is a prompt change, not a code change.

What if the Anthropic API is down?

Failed processing goes to a dead letter queue. When the API recovers, queued emails process automatically. You'll get a Slack alert if the queue backs up beyond a configurable threshold.

GDPR & Compliance

Is email data sent to Anthropic's servers?

Yes, but with zero-retention mode enabled. Anthropic's API doesn't store or train on data sent via the API when this is configured. The data transits their servers for processing only.

What about UK-to-US data transfers?

We'll provide Standard Contractual Clauses (SCC) documentation and a Transfer Impact Assessment. Anthropic supports these as a US-based processor. This is the standard legal mechanism for UK-to-US data transfers post-Brexit.

Do we need a DPIA?

Yes. Processing employee/customer emails through AI for automated complaint detection is likely to trigger the DPIA requirement under UK GDPR. We'll provide a completed DPIA template as part of Phase 1.

How does automated data retention work?

The retention engine runs on a schedule (configurable). It archives processed emails after X days and permanently purges them after Y days. Every action is logged to an audit trail. No manual cleanup is ever needed.

What about Subject Access Requests (SARs)?

The system includes a procedure document for handling SARs. Data is structured and searchable, so locating a specific person's data is a database query, not a manual hunt.

What are the ongoing costs?

AWS infrastructure: estimated $50-150/month. Anthropic API: estimated $20-100/month depending on email volume. No ongoing developer fees -- the system is designed for your team to manage.

Post-Deployment

What if something breaks after handoff?

Post-deployment support is included with no time limit. If the system needs attention, we'll fix it.

Can we modify the system ourselves?

The documentation package includes an admin runbook with common operations (adjusting alert thresholds, changing retention periods, adding email sources). For structural changes, you'd want engineering support.

How do we monitor costs?

CloudWatch dashboards show AWS costs and Anthropic API usage in real time. Billing alerts trigger automatically if spending exceeds configurable thresholds.

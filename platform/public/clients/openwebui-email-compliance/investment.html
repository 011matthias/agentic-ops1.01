Budget Context

Addressing the budget

The brief lists $600. Here's the honest breakdown of why this project costs more.

At $600, you'd get a Lambda function that calls the Anthropic API when an email arrives. That works for a demo. But for a 100+ person UK company processing customer emails:

  • You need GDPR compliance -- not as a nice-to-have, but as a legal requirement. That means retention automation, data minimization, transfer documentation, and a DPIA.
  • You need event-based architecture -- not a cron script. Emails should process in near real-time with retry logic and dead letter queues.
  • You need monitoring and alerting -- both for system health and API costs. Without it, a spike in email volume could run up thousands in API charges before anyone notices.
  • You need documentation and handoff -- the brief specifically says "fully manageable in-house without reliance on the developer." That's a deliverable, not an afterthought.

Phase 1 alone ($1,850) delivers the email monitoring system with full GDPR compliance. If that's where you'd like to start, we can scope Phase 2 separately.

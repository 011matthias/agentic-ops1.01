Day 1 Checklist

Here's what we cover in the first working session. You don't need to prepare anything beyond what's in the form above.

✓
Access granted to current account
Editor access confirmed so we can view scenario configurations, data stores, and connection details.
✓
First blueprint exports started
Every active scenario exported as a JSON blueprint. This is the source of truth for the audit.
✓
Initial dependency mapping begun
Which scenarios talk to which systems, which share data stores, and which have live webhook dependencies.
✓
Communication channel established
Primary contact confirmed, response time agreed on, and a shared space for questions and updates set up.
On webhook cutovers

Webhook URL changes are the highest-risk step of any migration. We schedule them in coordination with your sysadmin during a low-traffic window. No cutover happens without a confirmed rollback plan and a monitoring window afterwards.

Onboarding

What I need to start the core phase

Five things unblock day one. None of them require code from your side.

What unblocks the build

  • ERP interface docs and a test credential. Whatever your existing API or interface returns for tracking link, number, carrier, and status. This is the single most important item.
  • A dedicated All-Inkl mailbox or alias. Where shipment questions land, with IMAP and SMTP access for that mailbox only.
  • 20 to 30 real German tickets. Anonymized is fine. Both intents, including the messy and ambiguous ones. This becomes the test set.
  • Your reply tone. An example of how your team currently answers these, so the German templates sound like your shop.
  • The correction list. Which correction types you want handled, so we can check each against what the ERP can safely action.
Amazon comes in phase 2

Amazon Selling Partner API access is only needed for phase 2. Phase 1 ships on email alone, so you are not blocked waiting on Amazon developer approval to see the bot working.

System Architecture

The automation runs as a pipeline across three layers: an email trigger in n8n, an AI parsing layer using the Claude API, and a browser action layer using Playwright. A logging branch captures every decision to Google Sheets so you can audit what happened and why.

What each layer does

1
n8n IMAP trigger
Polls your email inbox every 1-2 minutes for new messages from Field Nation. Fires only for unread messages matching the sender pattern, so personal email isn't touched.
2
Claude API -- email parser
Receives the raw email body and extracts structured fields: job title, location, distance, pay rate, work type, scheduled date, and whether a counter-offer is available. Returns clean JSON every time, even when Field Nation changes email formatting.
3
n8n decision engine
Evaluates the parsed fields against your business rules (minimum pay rate, maximum travel distance, preferred work types). Outputs one of three actions: ACCEPT, REQUEST (counter-offer), or SKIP.
4
Playwright -- browser action
Opens a headless Chromium browser, logs into Field Nation using your stored session, navigates to the specific work order, and performs the action n8n decided. Takes a screenshot as a receipt. Handles session expiry and race conditions automatically.
5
Logging layer
Every step writes to Google Sheets: timestamp, job ID, title, pay rate, decision, action taken, and outcome. You get a full audit trail and can spot patterns over time (which types of jobs you're accepting most, average pay, etc.).

Data Flow

Here's what happens with a real example. A new email arrives from notifications@fieldnation.com with subject "New Work Order: Network Switch Installation in Miami, FL".

Step 1 -- Claude API parses the email

The raw email body is sent to Claude with a structured extraction prompt. It returns clean JSON regardless of how Field Nation formats the message:

{ "title": "Network Switch Installation", "location": "Miami, FL", "distance": "23 miles", "pay_rate": "$45/hr", "work_type": "Installation", "date": "2026-03-30 09:00", "counter_offer_available": true }

Step 2 -- Decision engine evaluates the job

n8n runs the parsed data through your business rules. With a minimum pay threshold of $40/hr and a maximum distance of 30 miles, this job clears both filters:

  • Pay rate: $45/hr -- above $40 threshold ✓ PASS
  • Distance: 23 miles -- within 30 mile limit ✓ PASS
  • Work type: Installation -- on accepted list ✓ PASS
  • Decision: ACCEPT

Step 3 -- Playwright executes the action

Playwright opens Field Nation in a headless browser, finds the work order using the job ID extracted from the email link, and clicks Accept. The screenshot is saved to your VPS and the result is logged to Google Sheets within about 20 seconds of the email arriving.

End-to-end latency

From email arrival to browser action completed: roughly 15-25 seconds. n8n polls every 60 seconds, so worst-case latency is around 85 seconds. That's still faster than you'll manually refresh your inbox.

Error Handling

Browser automation breaks in predictable ways. Here's what the system does in each scenario so you're not getting surprise failures at 2 AM:

Scenario Detection Response
Session expired Login page detected instead of dashboard Auto re-authenticate using stored credentials, retry the action
Work order already taken "No longer available" message on page Log as MISSED, move to next queued job
Email parse failure Claude API returns incomplete or malformed data Fall back to regex extraction; flag for manual review if both fail
Field Nation site down Page load timeout after 30 seconds Retry once after 60 seconds, then log ERROR and notify you
VPS resource issue Playwright process crash detected by PM2 PM2 auto-restarts the process; alert sent to you
MFA or CAPTCHA Challenge page detected before dashboard Pause automation, notify you to complete manually, then resume
On MFA

If Field Nation ever prompts for MFA during a session, the automation detects it and pauses rather than getting stuck in a loop. You'll get a notification with a link to log in manually. Once you do, the automation picks up where it left off.

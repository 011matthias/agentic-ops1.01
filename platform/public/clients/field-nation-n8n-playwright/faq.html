Frequently Asked Questions

Common questions about how the automation works, how your data is handled, and what happens after delivery.

Email Parsing

What if Field Nation changes their email format?

The Claude API parsing approach understands the meaning of the email, not just text patterns. When Field Nation updates their template -- and most platforms do this a few times a year -- the parser keeps working because it's reading for job title, pay rate, and location semantically.

If you prefer to skip the API cost, we can use regex parsing with a monitoring alert that fires when parsing fails, so you know immediately.

How much does Claude API cost for email parsing?

About $0.002 per email. If you process 50 work orders a day, that's roughly $3 per month.

The alternative is regex parsing at zero cost, but it breaks when email formats change. Both options are available -- you pick what fits your priorities.

Security

How are my Field Nation credentials stored?

Your credentials are stored in n8n's encrypted credentials store on your VPS. They never leave your server. Playwright uses these credentials to log in and maintain session cookies locally.

Can someone else see my automation activity?

The automation runs entirely on your VPS. No data is sent to external servers except the Claude API call, which receives the email text only -- not your credentials. All logs stay on your machine.

Business Rules

Can I change the business rules without developer help?

Yes. Your rules are stored in a Google Sheet (or n8n variables). To change the minimum pay rate, maximum travel distance, or preferred work types, you edit the sheet. The workflow reads the latest values on every run. No code changes needed.

Can I set different rules for different work types?

Absolutely. The decision engine supports per-work-type rules. For example: accept installations above $40/hr, skip surveys entirely, and request network jobs with a counter-offer at $50/hr.

Reliability

What happens if a work order is already taken?

The Playwright script checks the work order status before acting. If it's already accepted by someone else, the system logs "MISSED -- already accepted" and moves to the next work order.

You get a summary of missed jobs so you can adjust your email polling interval if needed.

How fast does it respond to new emails?

n8n's IMAP trigger polls at configurable intervals (default: 1 minute). From email detection to browser action is typically 30-60 seconds, depending on Field Nation's page load time.

For faster response, we can tighten the polling to 30 seconds or switch to a webhook-based trigger if your email provider supports it.

Ongoing Support

What's included after delivery?

One week of bug fixes for anything that breaks during normal operation. After that, we can set up hourly terms for ongoing development -- new rules, additional platforms, reporting, mobile alerts.

Can this be extended to other job marketplaces?

Yes. The architecture is modular: email parsing, decision engine, and browser automation are separate layers. Adding a new marketplace means building a new Playwright script for that site and connecting it to the same decision engine. The email parsing and logging layers stay the same.

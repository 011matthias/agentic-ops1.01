API Access

Which API keys do you already have?

Check the services you already have accounts for. We will set up credentials together securely during the kickoff call.

How we handle API credentials

We never ask you to paste API keys in a web form. During our kickoff call, we configure credentials directly in your n8n instance's encrypted credential vault. If you prefer asynchronous setup, we support:

  • n8n Credential Vault — enter keys directly in n8n's UI (encrypted at rest)
  • Password manager — shared vault via 1Password, Bitwarden, or similar
  • Upwork secure message — sent directly through the platform's encrypted messaging
No keys yet?

No problem. We can set up accounts together during Phase 1. Most services have free tiers that are sufficient for initial testing.

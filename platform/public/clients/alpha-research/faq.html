FAQ

Frequently Asked Questions

Honest answers to the questions we would ask if we were hiring for this project. Click any question to expand.

Scope

1 Why are you proposing to combine both jobs into one system?

Both share infrastructure: company registry, cloud storage, error handling, and the LLM extraction pattern. Building separately means duplicate storage logic, duplicate error handling, and two places to debug.

Combined means one system with two exportable workflow templates. You still get two independent n8n workflows, but they share a single company registry, a single storage layer, and a single error handling pattern.

2 Can you handle 300+ companies?

Yes. The dispatcher pattern batches companies into groups of 10-20. Each batch runs independently. Failed companies don't block others.

We test with 5-10 companies during build, then scale to the full list during the tuning phase. The architecture is designed for this from day one, not bolted on later.

3 What if I only want the web scraping pipeline, not the thesis/news part?

The workflows are separate n8n templates. You can run Workflow 1 (scraping) independently. The shared infrastructure (registry, storage) works for both but doesn't require both.

Technical

4 How do you handle JavaScript-rendered pages?

n8n has no native headless browser. We use an external browser API (ScrapingBee, Bright Data, or Apify) via the HTTP Request node. These services handle CAPTCHAs, proxy rotation, and browser fingerprinting.

Cost is approximately $0.001-0.01 per page, depending on the provider and complexity of the target site.

5 What AI model do you use?

Claude (Anthropic) for document link extraction, thesis synthesis, and relevance scoring. The prompt is customizable per use case.

Model choice is configurable in the workflow. You can swap to GPT-4o or others if preferred. The extraction logic is prompt-driven, not model-locked.

6 How does the HITL approval work technically?

The n8n Wait node pauses the execution. An HTML email is sent with signed Approve/Reject URLs (webhook endpoints with JWT tokens). Clicking either button hits the webhook, which resumes the paused execution.

There is a 7-day timeout with a day-3 reminder email. If no action is taken within 7 days, the execution expires without modifying any files.

7 What happens if my n8n instance restarts while a Wait node is active?

n8n persists execution state to its database. On restart, paused executions resume from saved state. The wait timeout resets, so the approval window effectively extends.

Delivery

8 What do I actually receive?

Two n8n workflow JSON files (importable into any n8n instance), a configured Google Sheets template (company registry), cloud storage folder structure, error handling documentation, and an operations guide.

Everything is yours to own and modify. No proprietary dependencies, no ongoing license fees.

9 Do I need my own n8n instance?

Yes. Either n8n Cloud (from $20/month) or self-hosted. The workflows are standard n8n JSON, compatible with any n8n installation.

10 Can I modify the workflows after delivery?

Yes, they are standard n8n workflows. No proprietary code, no lock-in. Every node is documented with sticky notes explaining what it does and why.

Risk

11 What if the scraping breaks when a company redesigns their site?

Expected for web scraping. The error handler logs failures with details about what broke. Per-company retry runs automatically on the next scheduled execution.

For JS-heavy sites, the browser API handles most structural changes. For major redesigns, the site type config in Google Sheets is updated. That is typically a 5-minute fix.

12 What if the AI extraction accuracy is poor for certain site types?

The prompt is tuned per-site-type during Phase 3 (tuning). We test accuracy against known document pages and adjust until classification confidence exceeds 85%.

Edge cases get site-specific prompt overrides stored in the company registry. This means you can fine-tune extraction for any individual company without affecting the rest.

13 What's your Upwork track record?

New on the platform, but we run production automation systems processing thousands of operations monthly for existing clients.

The live demo on the Workflow page proves the technical capability directly. We prefer demonstrating competence over describing it.

How It Works

Your investment research engine has two halves: data ingestion (scraping financial documents from 300+ company websites) and data processing (synthesizing analysis, filtering news, and routing updates through human approval). This system handles both as one unified pipeline.

📥
Data In
Where raw data enters the system
  • Google Sheets company registry
  • Investor relations web pages
  • AlphaVantage / SerpAPI / RSS
  • Google Drive file watcher
🤖
AI Processing
LLM extraction, classification, and synthesis
  • HTML link extraction + classification
  • Multi-document thesis synthesis
  • News relevance scoring
  • Material deviation detection
✅
Intelligence Out
Curated output with human approval
  • Cloud storage (organized by ticker)
  • Thesis updates (markdown)
  • Curated news digest (JSON)
  • HITL email approval
The real challenge

This looks like two separate projects, but it is one system with one hard problem: extracting structured data from unstructured sources. Whether it is parsing PDF links from an investor relations page or synthesizing thesis notes from five markdown files, the pattern is identical. LLM reads messy input, produces structured output, human approves. Designing it as one system means one storage layer, one error handling pattern, and one place to debug.

What We Build

Five pipelines that share a common company registry, storage layer, and error handling infrastructure. Two handle data ingestion, three handle intelligence processing.

1
Web Scraping Dispatcher
Reads 300+ companies from Google Sheets, dispatches to scraping sub-workflows in controlled batches.
2
Modular Document Scrapers
AI-powered link extraction from IR pages. Classifies and downloads financial documents to cloud storage.
3
Thesis Synthesis
Detects new analysis files, fetches 4 thesis docs, LLM synthesizes what needs updating.
4
News Intelligence Filter
Daily news scraping compared against Core Thesis. Flags material deviations, ignores noise.
5
HITL Email Approval
Nothing overwrites core files automatically. Email with Approve/Reject buttons and clean markdown append.
∞
Shared Infrastructure
Company registry, cloud storage, error handling, retry logic, execution logging across all pipelines.

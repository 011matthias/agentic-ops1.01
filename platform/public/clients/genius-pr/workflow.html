AI Classification Detail

Claude API is the intelligence layer for two of the three workflows: reply classification (Workflow 1) and call outcome analysis (Workflow 3). Each workflow uses a different prompt and returns a different structured JSON schema.

Claude API Intelligence Layer
Workflow 1: Reply Classification

Input: reply message body + campaign context. Output: HOT / WARM / COLD / NOT INTERESTED classification with confidence score and suggested response for HOT leads.

Workflow 3: Call Outcome Analysis

Input: Fathom transcript + Fathom AI summary. Output: WON / FOLLOW UP / NOT QUALIFIED outcome, key discussion points (3–5 bullets), next action step, and HubSpot-formatted deal note.

Structured JSON Output

All Claude responses are enforced as structured JSON using a system prompt schema. n8n parses the JSON node and routes based on field values. No unstructured text parsing.

Prompt Engineering

Prompts are stored as n8n variables, not hardcoded. You can tune classification criteria (e.g., "mentions budget = HOT") without touching the workflow logic.

Reply Classification Categories

Every email and LinkedIn reply is assigned one of four categories. The category determines the routing path.

HOT
Auto-respond with Calendly link. Slack alert to closer.
WARM
Log to CRM. Queue for manual follow-up. No auto-response.
COLD
Log to CRM. No action. Remains in sequence.
NOT INTERESTED
Log and suppress from future outreach sequences.

Confidence Threshold Gate

The 80% confidence gate is the safety mechanism that makes auto-response viable. When Claude is uncertain, the lead routes to human review instead of triggering an auto-reply.

Claude Confidence Score 0.0 → 1.0
0% — Uncertain Below gate: manual review Above gate: auto-respond 100% — Certain
Below 80% — Manual Review

Lead routed to Slack manual review channel. No auto-response sent. Closer reviews and responds manually. Classification still logged to CRM.

Above 80% — Auto-Response

For HOT leads: personalized reply sent immediately via originating channel (Instantly or HeyReach API) with your Calendly link. Response generated by Claude based on the original message context.

Threshold is configurable

The 80% threshold is set as an n8n variable. If you find too many leads going to manual review in the first week, we can lower it to 70%. If you want to be more conservative, raise it to 90%. No code change required.

Why shared outputs matter

When a lead replies to an email (Workflow 1), books a call (Workflow 2), and you run the call (Workflow 3), all three interactions land on the same HubSpot contact record in a consistent format. You see the full journey in one place.

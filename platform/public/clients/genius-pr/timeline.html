Phase 1: AI Reply Responder (Days 1–3)

The priority workflow. By end of Day 3, every reply from Instantly and HeyReach is being classified by Claude and routed automatically. This is the highest-ROI component and the one that starts working immediately.

Day 1
Foundation
  • n8n instance set up on Railway with credentials vault configured
  • Webhook endpoints created and tested with sample payloads
  • Claude API prompt engineering: classification schema, confidence scoring, response generation
  • HubSpot Private App token verified and scopes confirmed
  • All API credentials stored and tested in n8n credential vault
Day 2
Classification + Routing
  • Instantly webhook connected (reply_received event)
  • HeyReach webhook connected and payload normalized
  • Classification routing logic: HOT / WARM / COLD / NOT INTERESTED branches
  • Confidence threshold gate (80% default) wired in
  • HOT lead auto-response via Instantly API + HeyReach API tested
  • Manual review Slack channel for low-confidence replies
Day 3
Output Layer + Tuning
  • HubSpot contact create / update with deduplication by email
  • Google Sheets log row appended on every classification
  • Notion lead tracker entry created
  • HOT lead Slack alert with full summary formatted
  • Confidence threshold tuned based on test classifications
  • Error handling: failed writes alert to Slack, retry on 429s
End of Day 3 deliverable

Workflow 1 is live. Every email reply from Instantly and LinkedIn reply from HeyReach is being classified in real time. HOT leads get an auto-response with your Calendly link. Everything is logged to HubSpot, Sheets, Notion, and Slack.

Phase 2: Booking + Post-Call (Days 4–5)

With the AI responder live, we build the two supporting workflows. Day 4 handles bookings. Day 5 handles post-call intelligence.

Day 4
Booking Confirmation
  • Calendly webhook connected (invitee.created event)
  • HubSpot contact lookup by invitee email
  • Deal create or update: "Meeting Booked" stage transition
  • Google Sheets booked meetings log row appended
  • Notion booked meetings database entry created
  • Closer Slack alert: lead name, company, meeting time, source, prior classification
Day 5
Post-Call Intelligence
  • Fathom webhook connected (recording processed event)
  • Claude call outcome analysis: WON / FOLLOW UP / NOT QUALIFIED
  • Structured HubSpot note created on contact and deal
  • Deal stage updated based on outcome (WON = Proposal Sent, NOT QUALIFIED = Closed Lost)
  • Auto-create HubSpot follow-up task for FOLLOW UP outcomes (due 48 hours)
  • Slack outcome summary with recording link
Buffer
Overflow
  • Any credential delays or API access issues caught here
  • Additional prompt tuning if needed
  • Dripify alternative path if applicable
End of Day 5 deliverable

All three workflows are built and connected. The system now handles the full lead journey: reply → booking → post-call, with AI intelligence and structured CRM updates at every step.

Phase 3: Testing + Hardening (Days 6–7)

Building is 60% of the work. The other 40% is making it reliable. Days 6 and 7 are dedicated to real-lead testing, edge cases, and production hardening.

Day 6
Real-Lead Testing
  • 5 real lead replies tested end-to-end through Workflow 1
  • Verify correct classification for each lead
  • Confirm HOT auto-responses sent correctly via originating channel
  • Verify HubSpot records created with no duplicates
  • Verify Sheets rows, Notion entries, Slack alerts all correct
  • Test deduplication: same email through two entry points
Day 7
Harden + Handoff
  • Error handling audit: test each failure path (API down, timeout, rate limit)
  • Retry logic verified: 429 handling, exponential backoff
  • Slack error alerts confirmed for all failure scenarios
  • Monitoring setup: n8n execution log review process documented
  • Maintenance guide written (common issues + fixes)
  • Workflow JSON exported for each of the 3 workflows
Handoff
What You Receive
  • 3 live n8n workflows on your Railway instance
  • 3 exported workflow JSON files
  • Maintenance guide (PDF)
  • Walkthrough call (30 min)
  • All credentials documented in vault
End of Day 7: production ready

The system has been tested against real leads. Error handling is verified. You have the JSON exports, documentation, and a 30-minute walkthrough. From Day 8 onward, the system runs without intervention.

Prerequisites: What We Need on Day 1

The timeline only works if we have API access on Day 1. Credential delays are the single biggest risk to the 7-day delivery. Here is exactly what we need before we start.

Critical path

We can start building on Day 1 with partial credentials, but any missing credential delays the connected workflow. Instantly + HubSpot + Slack are the minimum needed to deliver Workflow 1 on schedule.

  • 📧
    Instantly API Key
    Settings → Integrations → API. Required for Workflow 1 (email reply handling + auto-response sending).
  • 👥
    HeyReach API Key + Webhook URL Configuration
    Settings → API Keys. You will also need to configure the webhook URL we provide in HeyReach's campaign settings. Required for Workflow 1 (LinkedIn reply handling).
  • 🔗
    Dripify: Confirm Approach
    Webhook support requires Pro plan ($59/mo). Confirm if you have Pro, or whether we handle LinkedIn via HeyReach only and use manual CSV export or Zapier bridge for Dripify.
  • 📅
    Calendly API Key + Webhook Subscription
    Settings → Integrations → API & Webhooks. Required for Workflow 2 (booking confirmation).
  • 📊
    HubSpot Private App API Token
    Settings → Integrations → Private Apps. Scopes required: contacts (read/write), deals (read/write), timeline events (write), tasks (write). Required for all three workflows.
  • 📈
    Google Sheets Access
    Service account or OAuth access to the Google Workspace. We create the logging spreadsheet, but we need write access to your Google Drive. Required for all three workflows.
  • 👥
    Notion Integration Token + Database IDs
    Settings → Connections → Develop or manage integrations. We need the token and the IDs of the databases to write to (lead tracker + booked meetings). We can create these if they do not exist.
  • 🎤
    Fathom API Key
    Settings → API Access. Required for Workflow 3 (post-call intelligence). Not needed until Day 5.
  • 💬
    Slack Bot Token
    Create a Slack app in your workspace with chat:write and channels:join permissions. We need the bot token and the channel IDs for HOT lead alerts and call outcome summaries.
  • 🤖
    Anthropic API Key
    console.anthropic.com → API Keys. Claude API usage is billed per token to your Anthropic account directly. Estimated cost: under $20/month at typical reply volumes.

The full credential checklist with setup instructions is on the onboarding page.

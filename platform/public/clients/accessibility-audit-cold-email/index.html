How It Works

Five n8n nodes in sequence. The workflow reads your sheet, audits each URL, writes results back, then routes failures into Instantly.ai -- all without manual steps between them.

1
Schedule triggers n8n workflow
Daily, weekly, or manual trigger. You control the cadence -- the workflow fires and handles everything from there.
↓
2
Google Sheets node reads URL batch
Reads the company name, URL, and contact email columns. Validates required fields before passing rows to the audit step.
↓
3
Code node launches Puppeteer, injects axe-core, captures violations
Headless Chrome loads the target URL, axe-core runs the WCAG 2.1 AA ruleset, and the violation array is returned to n8n for processing. Blocked or timed-out URLs are logged and skipped.
↓
4
Results written back to source sheet
Pass/fail status, total error count, and the top 3 violation types by frequency are written to the same row. The status column updates in place -- no duplicate rows.
↓
5
IF node routes failed sites to Instantly.ai API, logs to email tracking sheet
Only failed audits trigger outreach. The Instantly.ai API receives the contact email, company name, and a brief audit summary. A second sheet records every triggered email with a timestamp.

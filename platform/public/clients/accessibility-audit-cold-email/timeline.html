TIMELINE

9-Day Build Plan

Four phases. Each one has a clear deliverable before moving to the next.

Days 1-2
Server Setup and Sheet Template
n8n running on NameHero, Google Sheets template ready
  • SSH into NameHero, verify Node.js version, install n8n
  • Configure PM2 for process persistence (auto-restart on crash)
  • Set up reverse proxy for n8n web UI access
  • Test Puppeteer/headless Chrome on the server (critical compatibility check)
  • Create Google Sheet template with audit and email log tabs
  • Verify Puppeteer can execute -- if restricted, implement cloud function fallback
Days 3-5
Audit Workflow Build
Core pipeline: Google Sheets to axe-core results
  • Build Google Sheets read node (batch URL intake)
  • Implement axe-core Code node with Puppeteer launch, injection, and violation capture
  • Add user-agent rotation and stealth plugin for bot detection avoidance
  • Build error handling: timeout (15s), DNS failure, browser block -- all logged and skipped
  • Write results back to sheet: pass/fail, error count, top 3 error types
  • Test on 10 sample URLs, verify sheet output matches expected results
Days 6-7
Instantly.ai Integration
Cold email trigger for failed audits
  • Connect Instantly.ai API (campaign and lead endpoints)
  • Build IF node routing: FAIL status triggers email, PASS and BLOCKED skip
  • Map audit summary fields to Instantly email template variables
  • Create email log sheet (recipient, campaign ID, timestamp, audit summary)
  • Test end-to-end: audit a failing URL, verify Instantly sequence triggers
  • Verify API behavior matches your Instantly plan tier
Days 8-9
Scale Test and Handoff
Full 500-URL test, documentation, Loom recording
  • Run full batch of 500 URLs, monitor for memory and process limits
  • Verify all results written correctly, all emails triggered for failures
  • Record 10-15 minute Loom walkthrough explaining every node
  • Write troubleshooting documentation (what breaks, how to fix it)
  • Move all credentials to n8n credentials manager (nothing hardcoded)
  • Final review call before handoff
CHECKPOINT BETWEEN PHASES

You'll see results at the end of each phase. Phase 1 ends with n8n running on your server. Phase 2 ends with real audit results in your Google Sheet. Phase 3 ends with at least one Instantly sequence triggered. Nothing moves forward until the previous phase is verified.

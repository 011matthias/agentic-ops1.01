What We Need From You

Access checklist

  • 1
    n8n instance access — Viewer or editor role. We need to trace workflow execution paths and inspect node configurations.
  • 2
    Make.com organization access — Viewer role is enough. We'll review scenario structure, data mapping, and error handling.
  • 3
    Tier 2+: Chatbot platform and AI integration docs — Access to the chatbot platform admin and any documentation on your LLM or RAG setup.
  • 4
    Tier 3: Django codebase access — Read-only GitHub access works. We won't need production credentials or database access.
  • 5
    30-minute kickoff call — To understand your priorities and what's causing the most pain. This sets the audit focus.
We never need admin credentials

Viewer access is enough for the audit. We don't touch production data or make configuration changes during the review. Everything we do is read-only.

After the Audit

The audit report is the starting point, not the end. If you want us to implement the fixes, we can scope that as a follow-up engagement based on the audit findings. Implementation pricing is separate and based on the actual work identified.

We won't pad the audit with findings that require our services to fix. The report is structured to give you enough context to act independently or decide whether to bring us in for implementation.

What you can do with the report

Hand it to your existing dev team, use it to scope work independently, or ask us to implement the priority items. The report gives you that choice with real data, not guesswork.

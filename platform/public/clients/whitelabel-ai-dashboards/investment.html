Why hybrid

Fixed-price per build means you know the cost before starting and can set your own margin. The retainer ensures priority availability and covers support. No hourly tracking, no scope creep.

What the retainer covers

The retainer is not per-system. It covers ongoing support for every system we have built together. Prompt updates when AI models improve. New integrations as your clients adopt new tools. System health monitoring across all active deployments. Architecture reviews for new client types. Priority availability so you never wait.

What's Included

  • Complete dashboard + agent workflows per client system — built, tested, and deployed
  • Claude API prompt engineering — research and content prompts tuned for each client type
  • All tool integrations configured — calendar, email, CRM, task manager. Credentials stored securely
  • White-label branding — your logo, colors, domain. Client never sees UnpauseAI
  • Error handling and monitoring — Slack alerts on failures, automatic retry logic
  • Documentation and walkthrough — admin guide, maintenance runbook, recorded walkthrough
  • JSON export of all workflows — you own the code. Import into any n8n instance
  • Post-go-live support — ongoing support for every system built, included with retainer

What's Not Included

  • Tool subscription costs — n8n hosting (~$5–10/mo), Claude API usage (~$10–30/mo per client), email/CRM subscriptions. Billed to your accounts
  • Client-facing support — you handle all client communication. We support you, not your clients directly
  • Major new feature development — adding entirely new agent types or dashboard modules beyond the initial spec is a separate build
  • Design/branding work — we configure your existing brand assets. Logo design, brand guidelines, etc. are your responsibility

Value Context

Value context

Comparable agency builds run $5,000–15,000 per system. Our pilot at $2,000 is intentionally below that to prove the partnership. After the pilot, standard builds at $2,500–3,500 are still 30–50% below agency rates because automation infrastructure is all we do.

What the per-build price actually covers

The visible work is wiring APIs. The real work is everything that makes the system reliable for your client:

  • Prompt engineering: Without proper prompting, Claude returns generic summaries. We tune prompts with real data for each client type
  • Error handling: Without it, an API timeout causes the system to fail silently. Your client finds out days later
  • Edge cases: Without them, the dashboard shows stale data or the agent sends duplicate messages
  • Real data testing: Without it, the system looks correct on paper but misfires with actual client data

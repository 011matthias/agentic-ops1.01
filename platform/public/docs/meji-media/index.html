Where to Edit & Configure
What Where How
Email templates
Subject lines, body text, variants		 Make.com → Data Stores → Email Templates Click any template, edit subject or body_html, save. Changes take effect immediately.
Follow-up timing
Hours between emails per priority		 Make.com → Data Stores → Pipeline Config Edit cadence_hot_step2, cadence_warm_step2, etc. Values are in hours.
Lead scoring
Hot/warm/standard thresholds		 Make.com → Data Stores → Pipeline Config Adjust handoff_threshold (default: 50) and weight_* fields.
Handoff notifications
Who gets notified for hot leads		 Make.com → Data Stores → Pipeline Config Edit handoff_email field. Comma-separated for multiple recipients.
A/B testing
Enable/disable email split testing		 Make.com → Data Stores → Pipeline Config Set ab_testing_enabled to true or false.
Venue templates
Per-venue email personalisation		 Make.com → Data Stores → MM - Venue Config Edit venue-specific fields (features, tiers, phone, dates). 3 venues configured.
AI personalisation
Toggle AI-generated email openers		 Make.com → Data Stores → Pipeline Config Set ai_enabled to true/false. Model: ai_model field.
Email signature
Footer on all automated emails		 Make.com → Data Stores → Pipeline Config Edit email_signature_html. Updates all templates at once.

All configuration is in eu2.make.com. If you need help making changes, contact your automation specialist.

How It Works

Three automations work together, powered by Make.com:

A0 Poller → A1 First Email → A2 Reply Check → A3 Follow-Ups
  1. A0 polls your website database every 30 minutes for new enquiries
  2. A1 instantly logs the enquiry, scores the lead, and sends the first email
  3. A2 checks the inbox every 10 minutes -- if they reply, follow-ups stop
  4. A3 sends scheduled follow-ups and closes cold leads after ~9 days

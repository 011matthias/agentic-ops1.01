📌
A0, MySQL Enquiry Poller
Every 30 minutes · Always-on
  • 1Connects to enquiries table in your CRM database
  • 2Finds all rows with ID greater than the last-processed ID
  • 3Posts each new enquiry as a flat JSON object to A1's webhook URL
  • 4Saves the new cursor position so duplicates are never sent
⚡
A1, Enquiry Follow-Up Sequence
Instant webhook · Fires per enquiry
  • 1Fetches pipeline config and email templates from data stores
  • 2Scores lead across 9 factors using configurable weights
  • 3Assigns priority tier: hot (≥50) / warm (≥25) / standard
  • 4Assigns A/B variant (A or B), stored in sheet column Q
  • 5Calls OpenAI for a personalised one-sentence opening line
  • 6Logs row to Google Sheet (21 columns)
  • 7Routes: hot → team alert + warm ack; standard → initial email
🔋
A2, Reply Detection & Stop
Every 10 minutes · Gmail monitor
  • 1Scans Gmail inbox (enquire@christmasofficeparty.co.uk) for new replies
  • 2Matches reply sender to a row in the tracking sheet by email address
  • 3If found and not already stopped: sets stopped = TRUE, status = In Contact
  • 4A3 will never send further emails to a stopped lead
🕐
A3, Scheduled Follow-Up Steps
Every 60 minutes · Processes all due leads
  • 1Finds all leads where stopped = FALSE
  • 2Filters to only leads where next_step_due ≤ now
  • 3Reads A/B variant from column Q, uses matching template
  • 4Generates AI opening line, sends step 2 or step 3 email
  • 5Updates sheet: increments step, sets next due time per priority
  • 6Step 4+: marks as cold, stops the sequence

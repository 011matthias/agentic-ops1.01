# Video Script -- White-Label AI Systems Partnership

## Type: C (Proposal Site Walkthrough)
## Duration: 3 minutes (hard cap: 4 minutes)

---

## BEAT 1: Context + Reframe (20 seconds)

>> Camera on, clean desktop

SAY: Hi there, Nico here. I build AI agent systems. Claude Code and n8n are my daily tools.

SAY: I put together a full proposal site for your white-label AI partnership. Let me walk you through it.

SAY: This is not freelance automation. This is a systems partnership. You sell, I build.

>> Open browser to Overview page

---

## BEAT 2: Walkthrough (2 minutes 20 seconds)

### Overview (30 seconds)

>> Scroll to "Architecture" section, show three-zone diagram

SAY: The architecture is three layers. Dashboard shell on the left, that is what your client sees every day. Agent framework in the middle, that is Claude doing the actual work. Research, follow-ups, content drafts, task management. Integration bridge on the right, connecting to whatever tools the client already uses.

>> Scroll to "System Capabilities" cards

SAY: These layers combine into different systems depending on the client type. A real estate agent gets different agents than a startup founder, but they share 60-70% of the same base.

>> Scroll to "How We Work Together" timeline strip

SAY: The process is five steps. You send a brief, I build a spec, you approve, I build and test, you get a white-label system ready to deliver.

### Solution (30 seconds)

>> Click "Solution" in nav

SAY: The solution page breaks down each layer.

>> Scroll to "Dashboard Layer" section

SAY: Dashboard shell is lightweight HTML or Retool. Fast, responsive, white-label ready. Your branding, your domain.

>> Scroll to "Agent Layer" section

SAY: The agent layer is where Claude does the work. Each agent is a separate n8n workflow. Research agent, follow-up agent, content agent, task agent. Mix and match per client.

>> Scroll to "Tech Stack" table

SAY: Everything runs on n8n, open source and self-hosted. No per-execution fees. Your clients are not paying Zapier costs per task.

### Workflow + Live Demo (40 seconds)

>> Click "Workflow" in nav

SAY: The workflow page shows the full build process.

>> Scroll to "Live Demo: System Configurator"

SAY: Here is the live demo. I select a client type.

>> Select "Startup Founder" from dropdown, click "Configure System"

SAY: This is hitting the Claude API right now. It is analyzing what a startup founder needs and generating a tailored system configuration.

>> Wait for result to render

SAY: There it is. Dashboard panels, recommended agents, integrations, estimated build time. This is what I would spec out for that client type. Every configuration is generated from scratch based on the client profile.

>> Scroll to "What You Receive" section

SAY: Every build includes the working system, exported workflow files, documentation, recorded walkthrough, and two weeks of direct support.

### Timeline + Investment (30 seconds)

>> Click "Timeline" in nav

SAY: First build takes two to three weeks. After that, repeat builds drop to one to two weeks because the base components already exist.

>> Click "Investment" in nav

SAY: Pricing is hybrid. Fixed price per client system, $2,500 to $3,500. Monthly retainer of $1,500 for ongoing support. The first build is a pilot at $2,000 so we can test the partnership without a big commitment.

>> Scroll to "Market Comparison" table

SAY: For context, automation agencies charge $5,000 to $15,000 per system. We are well below that because automation infrastructure is all we do.

### Onboarding (10 seconds)

>> Click "Onboarding" in nav

SAY: The onboarding page has everything needed to start. Your details, first client brief, preferences. Fill it out and we start within 48 hours.

---

## BEAT 3: Close (20 seconds)

>> Camera on

SAY: So that is the full proposal. Three reusable layers, a repeatable build process, and a partnership model where you sell and I build. First system ready in two to three weeks.

SAY: If this model makes sense, the onboarding page has everything to kick off the pilot. Happy to jump on a call first if that is more useful.

SAY: Thanks for watching.

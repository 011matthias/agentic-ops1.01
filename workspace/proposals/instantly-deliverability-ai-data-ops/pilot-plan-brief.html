1Every score has a source

  • The model gets your ICP brief, the company's site and search results, and returns JSON: a fit score, the reasons, and a source URL for each claim.
  • Output that fails the schema, cites nothing, or scores under the line goes to a review tab, not the list.
  • Before a list loads, 20 rows are checked by hand against their sources. Where my read and the model's disagree, the prompt changes before the list ships.

2Every address is safe and new

  • A verifier checks that a mailbox exists, not that its mail server accepts cold mail. NeverBounce-valid addresses behind Mimecast bounced 10 times in 11 sends; behind Microsoft, once in 80.
  • The reverse holds too: "unknown" on Hotmail, iCloud and NHS is the server refusing the probe. All 335 such addresses we could check had already received mail, so they stay.
  • Each domain's mail server is read at load; Mimecast and no-MX addresses are held. Dedupe runs against every live campaign, the suppression list and open threads.

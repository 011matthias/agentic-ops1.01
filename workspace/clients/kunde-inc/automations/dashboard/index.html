Is This Data Live?

Yes. Every time you open this page (and every few minutes after), the dashboard calls three API endpoints running in the cloud. If those endpoints are reachable and return data, you see live data. The status bar at the top of the page shows the current state:

  • Green dot = Live data flowing from n8n endpoints
  • Amber dot = Partial data (some endpoints returning data, others unavailable)
  • Red dot = Offline (can't reach endpoints)

The data pipeline is Live — Smartlead campaign data syncs daily to Google Sheets, n8n endpoints serve the data, and this dashboard renders it in real time.

How Does It Work?

Three steps, every time you load the page:

1. You open this page
→
2. Dashboard calls 3 APIs
→
3. Data renders

The three API endpoints are hosted on n8n, a cloud automation platform. Each endpoint returns a different slice of data:

API EndpointWhat It ReturnsUsed By
/dashboard-campaignsAll 18 campaigns with metrics (leads, sent, open%, reply%, bounce%, meetings, cost)Overview table, stat cards, analytics
/dashboard-sequencesPer-step breakdown for each campaign's email sequence (50+ steps)Sequence drill-down, campaign detail modal
/dashboard-weekly24 weeks of historical trend data per campaignTrends tab charts, trend indicators

All authentication happens server-side. This dashboard contains no API keys or secrets — it just sends your login token to verify access.

What Is n8n?

n8n is a workflow automation platform (like Zapier, but self-hosted). It runs at unpauseai.app.n8n.cloud and does two things for this project:

  • API Endpoints: Hosts the 3 API endpoints that serve campaign data to this dashboard
  • Daily Sync: Runs scheduled automations that pull real data from Smartlead and store it in Google Sheets
  • Weekly Snapshots: Generates trend data for historical analysis

Think of n8n as the "backend" — it handles all the data logic, scheduling, and API responses. This dashboard is just the "frontend" viewer.

What's Configurable?

Click the gear icon (⚙) in the header to open Settings. You can adjust:

SettingWhat It Does
Auto-refreshToggle automatic data refresh on/off and set the interval (1, 5, 15, or 30 minutes)
Status barShow or hide the data health status bar
Data sourceLive endpoints (auto-detect)
Default tabWhich tab loads first when you open the dashboard
Decimal precisionHow many decimal places to show for rates (0, 1, or 2)

All settings are saved to your browser and persist across sessions.

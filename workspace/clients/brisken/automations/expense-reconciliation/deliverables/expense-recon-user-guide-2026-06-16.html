Expense Reconciliation, User Guide

How to match a month of card charges against receipts, review them, and produce the Zoho Books import.

What this tool does

It takes one card statement and its receipts, matches each charge to a receipt, suggests a category for every line, and gives you a review screen where you confirm or correct each charge. Once every charge is decided, it produces a Zoho Books journal import and an Excel review report. Everything runs on your own computer; no financial data leaves the machine.

1. Start the tool

  1. Open a terminal in the tool folder and run the command below.
  2. Your browser opens at http://127.0.0.1:8000. If it does not open on its own, type that address into the browser yourself.
  3. The address begins with 127.0.0.1, which means the tool is reachable only on this computer. Closing the terminal stops it.
expense-recon-web
First time only, if the command is not found, install the browser parts once from the project folder: uv sync --extra web

2. The three screens

The top bar of the tool has three links:

  • Runs: start a new reconciliation and reopen past ones.
  • Compare: put two runs side by side.
  • Memory: see and edit what the tool has learned.

3. Reconcile a month

  1. On Runs you need two files: the card statement (.csv or .xlsx) and the receipts file (.csv).
  2. Card / account name and Legal entity: short labels that say which card and which company this run belongs to, for example amex-9001 and brisken-llc.
  3. Card currency: the currency the card is billed in (USD by default).
  4. Receipts source: choose Extracted-fields CSV for the standard receipt export, or Zoho Expense export CSV if your receipts come straight from Zoho Expense. For the Zoho option a column map appears; leave it as is unless a header name differs in your file.
  5. Statement column overrides: the tool auto-detects the statement columns. Open this section only if a column was read wrongly.
  6. AI categorization: tick this to let the AI suggest categories and judge foreign-currency charges. It needs an OpenAI key set on the server. Without a key the tool uses its keyword classifier and still finishes the run.
  7. Click Run reconciliation. A progress screen appears; you can leave the tab, the work continues in the background.

4. The review screen

Working through each charge

  • A colored badge shows the state of the charge. Below it are the candidate receipts, each with a match score (amount, date, vendor) and the reason for the score.
  • If several receipts could fit, pick the right one with its radio button.
  • Confirm accepts the match; Reject says none of them fit; Reset clears your decision.
  • For an unmatched charge, use Match a receipt by hand to assign one yourself. You can take a receipt currently held by another charge; that other charge is freed.
  • Each receipt line has a category dropdown; change it if the suggestion is wrong.
  • If a line was auto-filled from memory and is wrong, click This was wrong. The tool forgets that merchant and lets you choose a category again.

The lists further down

Below the charges you will find: charges with no receipt, possible duplicates (nothing is removed, they are only flagged), receipts with no charge, and any rows that could not be read. Use them as a checklist before you finish.

5. Keyboard shortcuts

For faster review without the mouse:

  • j and k: move between charges.
  • c: confirm the selected charge.
  • r: reject the selected charge.
  • e: edit the category of the selected charge.
  • Ctrl or Cmd + K: jump to the filter box.

6. Finish and download

  • The bar at the bottom tells you whether you are Not ready to post or Ready to post. It also shows how many charges are still undecided, any amount still unreconciled, and how many lines still need a category.
  • Confirm all matched accepts every clean match in one click.
  • When the bar turns to Ready to post, two downloads unlock: Zoho journal (.csv) for import into Zoho Books, and Download report (.xlsx) as the review record.
The downloads stay locked until every charge is decided, so an incomplete month cannot be posted by accident.

7. Teach it for next month

Commit to memory saves what you confirmed: merchant categories, vendor name aliases, and foreign-exchange samples. Next month the tool auto-fills these, so each run is less work. Use it once you are happy with a run.

8. The Memory screen

Open Memory to see the merchant categories, vendor aliases, and FX histories the tool has stored. Forget on a row removes everything learned for that merchant, so the next run treats it as new.

9. Compare two runs

On Compare, pick two runs to see how the counts and each charge changed. This is most useful after you re-run the same month with a fixed receipt; across different months every charge simply shows as new on one side.

10. Good to know

  • Nothing is ever deleted automatically; duplicates and mismatches are only flagged for you to judge.
  • The downloads stay locked until every charge is decided, which prevents posting a half-finished month.
  • If a banner says no AI key is set, the run still completed using the keyword classifier. Set the key on the server only if you want AI categories.

Spesenabgleich, Benutzerhandbuch

So gleichen Sie einen Monat Kartenbuchungen mit den Belegen ab, prufen sie und erzeugen den Import fur Zoho Books.

Was dieses Werkzeug macht

Es nimmt einen Kartenauszug und die zugehorigen Belege, ordnet jede Buchung einem Beleg zu, schlagt fur jede Zeile eine Kategorie vor und zeigt Ihnen eine Prufansicht, in der Sie jede Buchung bestatigen oder korrigieren. Sobald alle Buchungen entschieden sind, erzeugt es einen Journal-Import fur Zoho Books und einen Prufbericht als Excel-Datei. Alles lauft auf Ihrem eigenen Rechner; keine Finanzdaten verlassen das Gerat.

  1. Offnen Sie ein Terminal im Werkzeug-Ordner und fuhren Sie den folgenden Befehl aus.
  2. Ihr Browser offnet sich unter http://127.0.0.1:8000. Falls er sich nicht von selbst offnet, geben Sie diese Adresse selbst im Browser ein.
  3. Die Adresse beginnt mit 127.0.0.1; das bedeutet, das Werkzeug ist nur auf diesem Rechner erreichbar. Wenn Sie das Terminal schliessen, wird es beendet.

2. Die drei Ansichten

Die obere Leiste des Werkzeugs hat drei Links:

  • Runs: einen neuen Abgleich starten und fruhere wieder offnen.
  • Compare: zwei Laufe nebeneinander stellen.
  • Memory: ansehen und bearbeiten, was das Werkzeug gelernt hat.

3. Einen Monat abgleichen

  1. In Runs brauchen Sie zwei Dateien: den Kartenauszug (.csv oder .xlsx) und die Belegdatei (.csv).
  2. Karten- / Kontoname und Rechtstrager (Legal entity): kurze Bezeichnungen dafur, zu welcher Karte und welcher Gesellschaft dieser Lauf gehort, zum Beispiel amex-9001 und brisken-llc.
  3. Kartenwahrung: die Wahrung, in der die Karte abgerechnet wird (Standard ist USD).
  4. Belegquelle: wahlen Sie Extracted-fields CSV fur den ublichen Beleg-Export oder Zoho Expense export CSV, wenn Ihre Belege direkt aus Zoho Expense kommen. Bei der Zoho-Option erscheint eine Spaltenzuordnung; lassen Sie sie unverandert, ausser ein Spaltenname weicht in Ihrer Datei ab.
  5. Spalten des Auszugs uberschreiben: das Werkzeug erkennt die Spalten automatisch. Offnen Sie diesen Abschnitt nur, wenn eine Spalte falsch gelesen wurde.
  6. KI-Kategorisierung: aktivieren Sie dies, damit die KI Kategorien vorschlagt und Fremdwahrungsbuchungen beurteilt. Dafur muss ein OpenAI-Schlussel auf dem Server gesetzt sein. Ohne Schlussel nutzt das Werkzeug den Stichwort-Klassifizierer und schliesst den Lauf trotzdem ab.
  7. Klicken Sie auf Run reconciliation. Eine Fortschrittsansicht erscheint; Sie konnen den Tab verlassen, die Arbeit lauft im Hintergrund weiter.

Jede Buchung durchgehen

  • Ein farbiges Abzeichen zeigt den Zustand der Buchung. Darunter stehen die Kandidaten-Belege, jeder mit einem Trefferwert (Betrag, Datum, Handler) und der Begrundung.
  • Wenn mehrere Belege passen konnten, wahlen Sie den richtigen uber den Auswahlknopf.
  • Confirm nimmt die Zuordnung an; Reject sagt, keiner passt; Reset loscht Ihre Entscheidung.
  • Bei einer nicht zugeordneten Buchung nutzen Sie Match a receipt by hand, um selbst einen Beleg zuzuweisen. Sie konnen einen Beleg nehmen, der gerade einer anderen Buchung zugeordnet ist; diese andere Buchung wird dann frei.
  • Jede Belegzeile hat ein Kategorie-Auswahlfeld; andern Sie es, wenn der Vorschlag falsch ist.
  • Wenn eine Zeile aus dem Speicher gefullt wurde und falsch ist, klicken Sie auf This was wrong. Das Werkzeug vergisst diesen Handler und lasst Sie die Kategorie erneut wahlen.

Die Listen weiter unten

Unter den Buchungen finden Sie: Buchungen ohne Beleg, mogliche Duplikate (nichts wird entfernt, sie werden nur markiert), Belege ohne Buchung und alle Zeilen, die nicht gelesen werden konnten. Nutzen Sie sie als Checkliste, bevor Sie abschliessen.

Fur schnelleres Prufen ohne Maus:

  • j und k: zwischen Buchungen wechseln.
  • c: die ausgewahlte Buchung bestatigen.
  • r: die ausgewahlte Buchung ablehnen.
  • e: die Kategorie der ausgewahlten Buchung bearbeiten.
  • Strg oder Cmd + K: zum Filterfeld springen.

6. Abschliessen und herunterladen

  • Die Leiste unten zeigt, ob Sie Not ready to post oder Ready to post sind. Sie zeigt auch, wie viele Buchungen noch offen sind, welcher Betrag noch nicht abgeglichen ist und wie viele Zeilen noch eine Kategorie brauchen.
  • Confirm all matched nimmt jede saubere Zuordnung mit einem Klick an.
  • Wenn die Leiste auf Ready to post wechselt, werden zwei Downloads frei: Zoho journal (.csv) fur den Import in Zoho Books und Download report (.xlsx) als Prufnachweis.
Die Downloads bleiben gesperrt, bis jede Buchung entschieden ist; so kann ein unvollstandiger Monat nicht versehentlich gebucht werden.

7. Fur den nachsten Monat anlernen

Commit to memory speichert, was Sie bestatigt haben: Handler-Kategorien, Namensvarianten von Handlern und Fremdwahrungs-Beispiele. Im nachsten Monat fullt das Werkzeug diese automatisch, sodass jeder Lauf weniger Arbeit macht. Nutzen Sie es, wenn Sie mit einem Lauf zufrieden sind.

8. Die Ansicht Memory

Offnen Sie Memory, um die gespeicherten Handler-Kategorien, Namensvarianten und FX-Verlaufe zu sehen. Forget in einer Zeile entfernt alles Gelernte zu diesem Handler, sodass der nachste Lauf ihn als neu behandelt.

9. Zwei Laufe vergleichen

Wahlen Sie unter Compare zwei Laufe, um zu sehen, wie sich die Zahler und jede Buchung verandert haben. Das ist am nutzlichsten, nachdem Sie denselben Monat mit einem korrigierten Beleg erneut laufen lassen; uber verschiedene Monate hinweg erscheint jede Buchung auf einer Seite einfach als neu.

10. Gut zu wissen

  • Es wird nie etwas automatisch geloscht; Duplikate und Abweichungen werden nur zur Beurteilung markiert.
  • Die Downloads bleiben gesperrt, bis jede Buchung entschieden ist; das verhindert das Buchen eines halb fertigen Monats.
  • Wenn ein Hinweis sagt, dass kein KI-Schlussel gesetzt ist, wurde der Lauf trotzdem mit dem Stichwort-Klassifizierer abgeschlossen. Setzen Sie den Schlussel auf dem Server nur, wenn Sie KI-Kategorien wunschen.

Conciliacao de Despesas, Guia do Usuario

Como conciliar um mes de lancamentos do cartao com os recibos, revisa-los e gerar a importacao para o Zoho Books.

O que esta ferramenta faz

Ela recebe um extrato do cartao e seus recibos, associa cada lancamento a um recibo, sugere uma categoria para cada linha e mostra uma tela de revisao onde voce confirma ou corrige cada lancamento. Quando todos os lancamentos estao decididos, ela gera uma importacao de lancamentos contabeis para o Zoho Books e um relatorio de revisao em Excel. Tudo roda no seu proprio computador; nenhum dado financeiro sai da maquina.

1. Iniciar a ferramenta

  1. Abra um terminal na pasta da ferramenta e execute o comando abaixo.
  2. Seu navegador abre em http://127.0.0.1:8000. Se nao abrir sozinho, digite esse endereco no navegador.
  3. O endereco comeca com 127.0.0.1, o que significa que a ferramenta so e acessivel neste computador. Fechar o terminal encerra a ferramenta.
expense-recon-web
Apenas na primeira vez, se o comando nao for encontrado, instale a parte do navegador uma vez a partir da pasta do projeto: uv sync --extra web

2. As tres telas

A barra superior da ferramenta tem tres links:

  • Runs: iniciar uma nova conciliacao e reabrir as anteriores.
  • Compare: colocar duas execucoes lado a lado.
  • Memory: ver e editar o que a ferramenta aprendeu.

3. Conciliar um mes

  1. Em Runs voce precisa de dois arquivos: o extrato do cartao (.csv ou .xlsx) e o arquivo de recibos (.csv).
  2. Nome do cartao / conta e Entidade legal (Legal entity): rotulos curtos que indicam a qual cartao e a qual empresa esta execucao pertence, por exemplo amex-9001 e brisken-llc.
  3. Moeda do cartao: a moeda em que o cartao e cobrado (USD por padrao).
  4. Origem dos recibos: escolha Extracted-fields CSV para o export padrao de recibos, ou Zoho Expense export CSV se seus recibos vierem direto do Zoho Expense. Na opcao Zoho aparece um mapa de colunas; deixe como esta, a menos que o nome de uma coluna seja diferente no seu arquivo.
  5. Substituir colunas do extrato: a ferramenta detecta as colunas automaticamente. Abra esta secao apenas se uma coluna tiver sido lida de forma errada.
  6. Categorizacao por IA: marque para a IA sugerir categorias e avaliar lancamentos em moeda estrangeira. Ela precisa de uma chave OpenAI configurada no servidor. Sem chave, a ferramenta usa o classificador por palavras-chave e ainda assim conclui a execucao.
  7. Clique em Run reconciliation. Uma tela de progresso aparece; voce pode sair da aba, o trabalho continua em segundo plano.

Tratando cada lancamento

  • Um selo colorido mostra o estado do lancamento. Abaixo dele ficam os recibos candidatos, cada um com uma pontuacao de correspondencia (valor, data, fornecedor) e o motivo.
  • Se varios recibos puderem servir, escolha o certo pelo botao de selecao.
  • Confirm aceita a associacao; Reject diz que nenhum serve; Reset apaga sua decisao.
  • Para um lancamento sem associacao, use Match a receipt by hand para atribuir um recibo voce mesmo. Voce pode pegar um recibo que esta atribuido a outro lancamento; esse outro lancamento fica livre.
  • Cada linha do recibo tem um seletor de categoria; altere-o se a sugestao estiver errada.
  • Se uma linha foi preenchida pela memoria e esta errada, clique em This was wrong. A ferramenta esquece esse fornecedor e deixa voce escolher a categoria de novo.

As listas mais abaixo

Abaixo dos lancamentos voce encontra: lancamentos sem recibo, possiveis duplicatas (nada e removido, apenas sinalizado), recibos sem lancamento e quaisquer linhas que nao puderam ser lidas. Use-as como lista de verificacao antes de finalizar.

5. Atalhos de teclado

Para revisar mais rapido sem o mouse:

  • j e k: mover entre os lancamentos.
  • c: confirmar o lancamento selecionado.
  • r: rejeitar o lancamento selecionado.
  • e: editar a categoria do lancamento selecionado.
  • Ctrl ou Cmd + K: ir para o campo de filtro.

6. Finalizar e baixar

  • A barra na parte de baixo informa se voce esta Not ready to post ou Ready to post. Ela tambem mostra quantos lancamentos ainda estao indecisos, qual valor ainda nao foi conciliado e quantas linhas ainda precisam de categoria.
  • Confirm all matched aceita toda associacao limpa com um clique.
  • Quando a barra muda para Ready to post, dois downloads sao liberados: Zoho journal (.csv) para importar no Zoho Books e Download report (.xlsx) como registro da revisao.
Os downloads ficam bloqueados ate que todo lancamento esteja decidido, para que um mes incompleto nao seja lancado por engano.

7. Ensinar para o proximo mes

Commit to memory salva o que voce confirmou: categorias de fornecedores, variacoes de nome de fornecedores e amostras de cambio. No mes seguinte a ferramenta preenche isso automaticamente, deixando cada execucao com menos trabalho. Use quando estiver satisfeito com uma execucao.

8. A tela Memory

Abra Memory para ver as categorias de fornecedores, as variacoes de nome e os historicos de cambio armazenados. Forget em uma linha remove tudo o que foi aprendido sobre aquele fornecedor, de modo que a proxima execucao o trate como novo.

9. Comparar duas execucoes

Em Compare, escolha duas execucoes para ver como os contadores e cada lancamento mudaram. E mais util depois de refazer o mesmo mes com um recibo corrigido; entre meses diferentes, cada lancamento simplesmente aparece como novo de um lado.

10. Bom saber

  • Nada e apagado automaticamente; duplicatas e divergencias sao apenas sinalizadas para voce julgar.
  • Os downloads ficam bloqueados ate que todo lancamento esteja decidido, o que evita lancar um mes pela metade.
  • Se um aviso disser que nenhuma chave de IA esta configurada, a execucao ainda foi concluida com o classificador por palavras-chave. Configure a chave no servidor apenas se quiser categorias por IA.

# OneProposal, quick synopsis

**For:** Dirk · **From:** Matthias · 2026-07-07 · quick brief, as you asked

**What it is.** OneProposal is our (UnpauseAI) tool that turns a job brief
or project description into two things in about 30 seconds: a tailored
cover letter written in your own voice, and a personalized one-page
proposal site at its own public link. You paste the brief, confirm we
read it right (it pulls out the prospect, the problem, the budget and the
timeline, all editable), and it generates both. Live now at
app.unpauseai.com; $5 per proposal, refunded if the output is not usable.

**Purpose.** Kill the generic-AI-proposal problem. Most proposals now
read like ChatGPT wrote them: the same opener, the same "I'm excited
about this opportunity," the em-dashes, so prospects skim past them.
OneProposal is built the other way round: research-first, not
template-first, with a hard constraint set (banned phrases, em-dash
sanitizing, quote-the-brief-back) so the output reads like a person
wrote it. And every proposal gets a real hosted page, the polish almost
no one bothers with.

**Value add.**

- A proposal that does not pattern-match to AI, so it actually gets read.
- A personalized page at a link, not just a block of text; the prospect
  opens a clean page that looks like an agency built it.
- Cheap and fast per proposal ($5, pay per use, no subscription), with
  three regenerate angles (shorter, different angle, push back on price)
  if the first pass misses.
- Your data stays yours: scoped to your account, never shared or
  trained on.

**Plan to execute, and how it maps to what you asked.** The product is
live today for the freelancer / Upwork use case. What you described,
hanging your own finished proposal on the site for one client, gated, is
a slightly different shape: less "generate a proposal," more "host and
gate one you already wrote." That is the smaller near-term step, and it
is exactly what the interim gated slot we talked about bridges: I stand
up an unlinked, password-protected page for your finished proposal now,
customer-only, and we fold it into OneProposal properly once the
hosting-and-gating side is productized. On the generation side the next
build items are inline editing of the rendered page and volume tiers.

**So, concretely, for you.** Short term: I give you the gated slot for
the proposal you already have; I just need the file and a word on which
site it hangs on (brisken.com or the OnePilot site). Medium term:
OneProposal becomes the standing way to produce and host client-facing
proposal pages, on brand, in minutes.

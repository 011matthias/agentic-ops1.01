## Before you start

1. **Send WITH notes.** Dirk's account is on Premium per Matthias (2026-07-11), which carries the 300-character note limit and a note-invite allowance that fits 29 invites. One sanity check before the first batch: open any profile, click Connect, then Add a note; Premium shows a 300-character counter. If it shows 200 (free), stop and send note-less instead; every note below is 160 characters or fewer, so it fits either way.
2. **Pace at about 20 invites a day, spread through the day.** 29 fits in two calendar days.
3. **If already a 1st-degree connection, skip the invite** and send the note text as a direct message instead.
4. **Identity check before every send.** Use the `resolved_linkedin_url` column when it is filled (24 of 29). Five contacts have no verified profile; find them via the Sales Nav search URL and confirm the person against the `job_title` column in `tier3-roster.csv` before inviting. On a name collision, skip and flag; a wrong invite goes out under Dirk's name.
5. **No pitch, no consent language.** These are relationship connects for the Brisken Token network. The GDPR notice about the token data is a separate email owned by the "Rome booth/token-network: GDPR consent email" task and must not leak into these notes.

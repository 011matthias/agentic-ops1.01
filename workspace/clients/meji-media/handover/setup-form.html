Before You Start

This wizard will set up your automated enquiry follow-up system in about 5 minutes. Make sure you have the following ready before you continue.

  • Make.com account
    Don't have one? Sign up here (free plan works to start).
  • Google account with Gmail and Sheets
    This is the account that will send follow-up emails and own the tracking spreadsheet. Use a shared/team inbox if you have one.
  • OpenAI API key
    Used to generate personalised email opening lines. Create one here — costs ~$0.01 per enquiry.
  • Downloaded files from the link we sent you
    You should have these files saved on your computer:
    s0-environment-setup.json
    a1-template.json
    a2-template.json
    a3-template.json
    Make sure they're all in the same folder so they're easy to find.
Import the Setup Scenario

First, we need to import a one-time setup scenario into your Make.com account. Follow these steps exactly:

1
Log into Make.com and click Scenarios in the left sidebar.
2
Click Create a new scenario (top-right corner).
3
You'll see a blank canvas. Click the "…" (three dots) menu in the top-right corner and select Import Blueprint.
4
Select the file s0-environment-setup.json from the files you downloaded, then click Save.
5
Make.com will show the scenario and ask you to set up connections. You'll see prompts for Google Sheets and Gmail — click each one and sign in with the Google account you want to use for sending emails and owning the spreadsheet.
6
Click the big purple Run once button at the bottom-left of the canvas. The scenario will show "waiting for data" — that's normal.
7
Click the first circle on the far left (labelled Webhooks). You'll see a URL — copy it. You'll paste it in the next step.
Keep your Make.com tab open — the scenario is waiting for data. You'll come right back to the next step here.

Test It

Run a quick test to make sure everything is working:

1
Connect your website contact form to the A1 webhook URL above. Details for your web developer

The A1 webhook expects form submissions in Tally format (nested fields array). If you use Tally for your contact form, just point it at the webhook URL — no extra setup needed.

If you use a different form tool, your developer needs to send a POST request with this structure:

{
  "data": {
    "fields": [
      { "label": "What's your name?", "value": "..." },
      { "label": "Email address", "value": "..." },
      { "label": "Phone", "value": "..." },
      { "label": "Discussion Topic", "value": "..." },
      { "label": "Organisation Name", "value": "..." },
      { "label": "A brief description about your project/request/consultation", "value": "..." }
    ]
  }
}

Important: The field labels must match exactly (including punctuation and capitalisation).

2
Submit a test enquiry through your website contact form (use a personal email you can check).
3
Open your Google Sheet (open spreadsheet). A new row should appear within about 30 seconds.
4
Check the inbox of the test email address you used. A follow-up email should arrive within a minute or two.
If all checks pass — you're live! Every new enquiry will now be automatically logged, scored, and followed up.

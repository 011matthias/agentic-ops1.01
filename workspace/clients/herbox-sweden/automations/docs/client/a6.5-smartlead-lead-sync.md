# SmartLead Lead Sync

Automatically syncs validated leads from Airtable to your SmartLead campaigns in real-time.

## What This Does

When a lead in your Airtable Contacts table is marked as "Ready for Sync", this automation:

1. Fetches the complete lead information from Airtable
2. Validates the lead has a campaign assigned and valid email
3. Maps all the lead data to SmartLead's format
4. Adds the lead to the assigned SmartLead campaign
5. Updates the lead's status in Airtable to show it was successfully added

**Runs:** Immediately when a lead's "Outbound Status" changes to "Ready for Sync"

## How It Works

1. **Airtable triggers the sync** - When you change a lead's status to "Ready for Sync", Airtable sends a notification to the automation
2. **Lead validation** - The automation checks that the lead has a campaign assigned and a valid email address
3. **Data mapping** - All lead information is formatted for SmartLead:
   - Name fields (first name, last name)
   - Email address
   - Company information
   - Job title
   - Website
   - LinkedIn profile
   - Personalized message
4. **Sync to SmartLead** - The lead is added to the campaign specified in Airtable
5. **Status update** - Airtable is updated to show "Added to Campaign" with the SmartLead contact ID

## What You'll See

When this automation runs successfully, you'll see:

- **In Airtable:** The lead's "Outbound Status" field changes to "Added to Campaign"
- **In Airtable:** The "SL Contact ID" field is populated with the SmartLead lead ID
- **In SmartLead:** The lead appears in the assigned campaign and begins receiving emails
- **In Dashboard:** A success log entry showing the sync was completed

## Lead Information Synced

The following fields are sent from Airtable to SmartLead:

| Airtable Field | SmartLead Field | Description |
|----------------|-----------------|-------------|
| SL_firstName | First Name | Cleaned first name |
| Last Name | Last Name | Contact's last name |
| Email | Email | Verified email address |
| SL_company | Company Name | Normalized company name |
| Website | Website | Company website (first if multiple) |
| SL_title | Job Title | Dutch title translated to English |
| SL_Personalization | Personalization | Custom message for this lead |
| Linkedin URL | LinkedIn Profile | Full LinkedIn profile URL |

## Status Meanings

When you check the "Outbound Status" field in Airtable, you may see:

| Status | What It Means |
|--------|---------------|
| Ready for Sync | Waiting to be synced (change to this to trigger sync) |
| Added to Campaign | Successfully synced to SmartLead campaign |
| Sync Error | Something went wrong - check "Sync Error Log" field |
| Invalid Email | Email address failed validation, cannot be synced |

## When Leads Are Skipped

The automation will skip syncing a lead if:

- **No campaign assigned** - The "Campaign ID" field is empty
- **Missing email** - The "Email" field is empty
- **Invalid email** - The "Email Verification Status" is marked as "Invalid"

Skipped leads don't count as errors - they simply aren't ready for outreach yet.

## Troubleshooting

### Lead not syncing to SmartLead

**Check these in Airtable:**
1. "Campaign ID" field has a value
2. "Email" field is not empty
3. "Email Verification Status" is not "Invalid"
4. "Outbound Status" is set to "Ready for Sync"

**If all looks good:**
- Check the automation dashboard logs for any error messages
- Look at the "Sync Error Log" field in Airtable for details

### "Sync Error" status appears

When you see this status:

1. Look at the "Sync Error Log" field in the same Airtable record
2. Common causes:
   - Campaign doesn't exist in SmartLead
   - Campaign ID is incorrect
   - SmartLead API is temporarily unavailable

**What to do:**
- Fix the issue (e.g., correct the campaign ID)
- Change "Outbound Status" back to "Ready for Sync" to retry

### Duplicate leads in SmartLead

SmartLead automatically handles duplicate detection:
- Same email cannot be added to the same campaign twice
- Same email can exist in different campaigns
- The automation respects SmartLead's duplicate settings

### Lead synced but not appearing in campaign

**This usually means:**
- The lead was added successfully but might be in a "Not Started" status
- Check the SmartLead campaign to see the lead in the full leads list
- It may take a few minutes for SmartLead to process and start the sequence

## Example

### Before (Manual Process)

1. Export leads from Airtable to CSV
2. Open SmartLead
3. Navigate to campaign
4. Import CSV file
5. Map fields manually
6. Wait for import to complete
7. Manually update Airtable to track which leads were added

**Time per batch:** 15-30 minutes

### After (Automated)

1. Change lead status to "Ready for Sync" in Airtable
2. Lead automatically appears in SmartLead campaign within seconds
3. Airtable automatically updates with sync status

**Time per lead:** 0 minutes (instant)

## Multiple Campaigns

If a lead has multiple campaign IDs assigned:
- The automation uses the **most recent** (last) campaign ID
- This allows you to reassign leads to different campaigns
- The lead will be synced to whichever campaign is listed last in the array

## How to Trigger Manually

To manually sync a lead:

1. Open the lead record in Airtable
2. Change the "Outbound Status" field to "Ready for Sync"
3. The automation triggers immediately
4. Within a few seconds, the status updates to "Added to Campaign"

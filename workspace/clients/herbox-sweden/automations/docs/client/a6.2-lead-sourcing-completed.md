# Lead Import from Apify Scrapers

Automatically imports scraped leads from Apify into Airtable the moment scraping completes.

## What This Does

When your Apify scrapers finish running (from LinkedIn Sales Navigator or Apollo), this automation immediately:

1. Fetches all the leads that were scraped
2. Organizes them into contacts and companies
3. Imports them into Airtable with proper linking
4. Updates your list status so you know scraping is done

**Runs:** Automatically triggered by Apify when a scraper finishes (webhook-based)

## How It Works

### 1. Scraper Finishes
When an Apify scraper completes, it sends a notification to our system with the run details.

### 2. Fetch the Data
The automation downloads all the scraped leads from Apify's dataset storage.

### 3. Organize Contacts and Companies
- Identifies unique companies (no duplicates even if multiple people work there)
- Normalizes data from different scraper formats (Apollo vs Sales Navigator)
- Links contacts to their companies automatically

### 4. Import to Airtable
- Adds or updates contacts in the Contacts table
- Adds or updates companies in the Accounts table
- Links contacts to their companies
- Tags everything with your list name

### 5. Update Status
Changes your list status to "Scraper Completed" so you know it's ready for enrichment.

## What You'll See

When this automation runs successfully, you'll see:

### In Airtable
- New contacts appear in your Contacts table
- New companies appear in your Accounts table
- Contacts are automatically linked to their companies
- All records are tagged with your list name
- List status changes to "Scraper Completed"

### In the Dashboard
- Success notification showing how many contacts and accounts were imported
- Example: "Upserted 438 contacts, 171 accounts"

### If Something Goes Wrong
- Error messages appear in the "Scraper Log" field of your list record
- Dashboard shows failed status with error details
- You'll be notified if self-healing webhook is configured

## Example

### Before (Manual Process)
1. Wait for scraper to finish (no notification)
2. Download CSV from Apify manually
3. Clean up data formats in spreadsheet
4. Import to Airtable (deal with duplicates)
5. Manually link contacts to companies
6. Update list status

**Time:** 30-60 minutes of manual work

### After (Automated)
1. Scraper finishes → automation runs automatically
2. All data imported and organized within 2-3 minutes
3. Everything ready for next step (enrichment)

**Time:** Zero manual work

When you check your list records, you may see these statuses:

| Status | What It Means |
|--------|---------------|
| Scraping | Apify is currently running |
| Scraper Completed | Data successfully imported (this automation) |
| Failed | Scraper or import failed - check Scraper Log field |
| Auto-resolved | Had an issue but fixed itself automatically |

## Data Quality Features

### Deduplication
- **Companies:** Only creates one account per LinkedIn company URL (even if 50 people work there)
- **Contacts:** Updates existing contacts if they're already in Airtable (matches on LinkedIn URL)

### Smart Formatting
Handles data from different scrapers:
- Apollo scraper format (fields like `first_name`, `organization.name`)
- Sales Navigator format (fields like `firstName`, `companyName`)

Both formats get normalized to the same Airtable structure automatically.

### Contact-to-Company Linking
- Automatically links each contact to their company
- Uses LinkedIn company URLs to ensure accuracy
- Handles special characters in URLs correctly

## Troubleshooting

### "Scraper failed" in Scraper Log
**What happened:** The Apify scraper encountered an error

**What to do:**
1. Check the Apify console for the specific error
2. Common causes: Invalid search criteria, LinkedIn rate limits, proxy issues
3. Fix the scraper settings and run again

### "List not found for Scraper ID"
**What happened:** The automation can't find which list this scraper belongs to

**What to do:**
1. Make sure the list record has the "Scraper ID" field filled in
2. Verify it matches the Apify run ID
3. Contact support if the issue persists

### No contacts imported (empty dataset)
**What happened:** The scraper ran successfully but found 0 leads

**What to do:**
1. Check your scraper search criteria in Apify
2. Verify the target URL/search terms are correct
3. Try running the scraper manually in Apify first

### Some contacts not linked to companies
**What happened:** The contact's company didn't have a LinkedIn URL

**What to do:**
- This is normal for some scrapers/sources
- The contact is still imported, just without the company link
- You can manually add the company link in Airtable if needed

## Technical Details

### Batch Processing
The automation processes leads in batches of 5 to respect Airtable's rate limits. For a typical dataset of 400+ leads, this takes 2-3 minutes.

### Webhook Configuration
The Apify webhook should be configured to send both:
- "Run succeeded" events → imports data
- "Run failed" events → logs error to Scraper Log

## Notes

**GPT Prompts:**
- Company name prompt is detailed with specific rules for legal entities, special chars, word limits
- Job title prompt is Dutch and asks for lowercase, context-aware translations

**Parallel Processing:**
- Accounts and contacts are cleaned concurrently
- Rate limiting: 0.5s delay between GPT calls to avoid rate limits

**Cost-Saving Tips:**
- Run with `--dry-run` first to estimate volume
- Process in batches if you have thousands of records
- Consider running weekly instead of daily if volume is low

**Common Issues:**
- Empty company names → Skipped with warning
- Missing websites → Still processed (best-effort)
- Unexpected GPT format → Stored as-is, manual review needed
- Rate limits → Automatic retry with backoff

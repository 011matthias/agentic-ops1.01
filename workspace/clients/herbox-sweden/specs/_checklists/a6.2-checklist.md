## Notes

**Blocker mentioned:** Need an Apify element for full testing. Workaround is using a different API for testing or mocking the Apify client.

**Special considerations for A6.2:**
1. This is a **webhook-triggered** automation - testing requires either:
   - Running the FastAPI server locally and sending curl requests
   - Deploying to Railway and configuring Apify webhooks
   - Running directly with a JSON payload file (use `--dry-run` flag)

2. **Data transformation** handles two different scraper formats - test both:
   - Apollo format: `first_name`, `last_name`, `linkedin_url`
   - Sales Nav format: `firstName`, `lastName`, `publicUrl`

3. **Deduplication** uses LinkedIn URL as merge key - ensure test data has:
   - Some new contacts (should create)
   - Some existing contacts (should update)

4. **Apify dependency:** For full integration test, you need a real Apify run with a dataset. Workaround:
   - Use a past successful run's dataset ID
   - Mock the Apify client in tests (already done in unit tests)

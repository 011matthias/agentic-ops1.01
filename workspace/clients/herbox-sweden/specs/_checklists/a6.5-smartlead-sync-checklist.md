## Status Values

The automation sets these `Outbound Status` values:

| Status | Meaning |
|--------|---------|
| Added to Campaign | Successfully synced to SmartLead |
| Sync Error | Failed to sync (check `Sync Error Log`) |
| Invalid Email | Email verification status = Invalid |

## Notes

**Rate Limiting:** SmartLead allows ~5 requests/second. The client has built-in rate limiting (200ms delay).

**Duplicate Handling:** SmartLead automatically handles duplicate leads within the same campaign based on email address.

**Background Processing:** The webhook runs in a FastAPI background task, so it returns 200 immediately while processing continues.

**Logging:** All steps are logged to the execution logger database. Check dashboard for detailed logs.

**Troubleshooting:**
- If sync fails, check `Sync Error Log` field in Airtable
- Verify SmartLead API key is valid
- Verify campaign ID exists in SmartLead
- Check that lead email is valid and not already in campaign (if duplicates are not allowed)

# Tools Manifest

One-line index of `tools/` scripts. Auto-loaded at session start to reduce `missed-tool` friction (5+ register entries where a tool existed but wasn't found).

| Tool | When to use |
|------|-------------|
| `validate-output.py FILE` | Universal text validator (em-dashes, brand misspellings, AI-tells, fabrication risk, `unsourced-claim`: client-facing problem-claims with no source attribution within ±2 lines; B4/register #7). Markdown files also get the two rule_anti_slop structural detectors, `symmetry-collapse` + `per-category-narration` (both LOW/advisory). Auto-fires via post-write-gate hook on any file in deliverable or comms scope. |
| `validate-deliverable.py FILE.html` | HTML deliverable QoL features check (dark mode, copy-clipboard, Ctrl/Cmd+K, state persistence) per rule_deliverables.md. Auto-fires on HTML writes. |
| `validate-html.py FILE.html` | HTML structural validation (unclosed tags, duplicate IDs, missing head, relative paths). B2 gate extension before deploy. Use `--dir` for cross-page consistency. |
| `validate-demo-material.py FILE...` | Banned-**content** scan for client-facing demo material, as opposed to banned *language*. Reads what actually ships: PDF page text, `.pptx` slide XML (catches hidden slides and terms split across runs), captions, HTML/markdown, and generators before they run. Terms come from client directives in `tools/fixtures/demo-banned-terms.json` (Brisken: no SAP BTP, per Dirk's "Exclude BTP from all demos"). Exit 1 on any unexempted hit. B2 gate before any deck, PDF or video reaches a client. `--dir`, `--client brisken`, `--list-terms`, `--format json`. Auto-fires via post-write-gate on text writes under `workspace/clients/*/deliverables/**` and `*/resources-site/**` when the client has a fixture entry; binary renders (PDF/pptx/mp4) still need the manual run or a render tool that self-gates. |
| `brisken-sap-onepagers.py [--out DIR]` | Source of truth for the 6 Brisken SAP Resources one-pagers (dark-cockpit brand). Default `--out` is the sap-assets deliverables dir; resources-site sync stays a separate manual step. |

| `bg_watch.py watch --label L [--eta MIN] [--heartbeat PATH] \| list \| check \| done ID` | Background-work liveness watches: the structural detector for "the background phase you are relying on is dead" (2026-07-22 register: a verify fan-out died at 5 min, went unnoticed for 76, and 35 of 38 findings shipped presented as verified). | `pin_scorer.py pin <name> [--pr N] \| pin-guard <tools/path.py> [--pr N] \| check \| list` | Scorer pin registry tool for `tools/scorers/PINS.json` (name -> content-hash + direction, CRLF-normalized git-blob sha). `pin` refuses without `SCORER_LOCK_ALLOW=1` (the same user-approval seam that gates scorer edits); `check` exits 1 on any drift/unpinned/orphan (run by CI). Tests: `test_guard_pins.py`. |
| `optimize_overview.py [--project SLUG] [--scoreboard] [--prior-art PROJECT] [--sweep [--once-per-day]]` | Read-only fleet view of ALL optimize runs across projects (RECIPES.md "Many projects" convention). ## Output validators — JSON contract

`validate-output.py`, `validate-deliverable.py`, `validate-html.py`, `lint-comms-draft.py` all support `--format json` and emit:

```json
{
  "total": N,
  "hits": [{"line": N, "category": "...", "severity": "HIGH|MEDIUM|LOW", "message": "...", "snippet": "..."}],
  "by_category": {"category": N, ...},
  "by_severity": {"HIGH": N, ...}
}
```

Severity HIGH = ship-blocker, MEDIUM = strong warning, LOW = nudge. The post-write-gate hook surfaces HIGH first.

## Suppression markers

- **validate-output.py**: `<!-- output-allow:CATEGORY[,CAT2][:N_LINES] reason text -->` on the line before a hit (or `:N` to suppress next N lines).
- **validate-deliverable.py**: `<!-- deliverable-allow: CATEGORY[, CAT2] | reason: ... -->` anywhere in the file (suppresses globally for that category).
- **validate-html.py**: no suppression — structural failures should be fixed, not muted.

## Adding a new tool

1. Use `# /// script\n# requires-python = ">=3.11"\n# ///` PEP 723 header for inline deps.
2. Run via `uv run tools/{name}.py`.
3. If callable from a hook, support `--format json` and exit 0 even on hits (the hook reads JSON, not exit code).
4. Add a one-liner to this INDEX.

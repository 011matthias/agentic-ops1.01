## Key Decisions Made
### Deck pages are now generated, not hand-written
- **Choice:** `page_deck()`/`DECKS` in the generator emit the 3 deck pages.
- **Rationale:** Reformatting them to the one-pager frame reused `WEB_CSS`; generating keeps them reproducible and consistent. Supersedes the memory note "deck viewer pages are hand-edited, not generated."

### Home is a bespoke static index.html (authored via a scratch script)
- **Choice:** The full-bleed home was generated by an ephemeral `scratchpad/gen_index.py` that embeds the two logos; the committed artifact is `index.html` itself.
- **Rationale:** Editing an 88KB base64-heavy file in place is fragile; a generator script avoids that. The script is throwaway (scratch), so `index.html` remains the source of truth. Candidate improvement: fold index generation into `tools/brisken-sap-onepagers.py` for reproducibility.

### Page title "Products"; hero "Treasury products, built into SAP"
- **Choice:** Renamed from "Product Deck". Hero summary just names the six products; trust strip reuses the approved PROOF badges.
- **Rationale:** Products became the primary content; copy stays sourced (no new claims), Bank Fee / TreasuryCentral keep the no-unbacked-customer restraint.

- Live reads: `python <scratch>/api.py GET /api/path "<python expr on d>"` (bearer from `POST /api/login` with `EXPENSE_RECON_OPERATOR_CODE` from `workspace/clients/brisken/context/.env`, held in memory only). `MSYS_NO_PATHCONV=1` for every `/api/...` arg in Git Bash. - Never `git stash`. Stage explicit paths. Never `git checkout --` to restore a backup (it restores from HEAD); use a `cp` backup and a `cp` restore. The primary clone runs behind origin/main: use `( cd X && ... )` or `git -C`; a bare `cd` is blocked by a hook. **Patch CRLF sources in BYTE mode** (`read_bytes`/`write_bytes`): text mode flattens the whole file's endings and turns a small edit into a whole-file diff.

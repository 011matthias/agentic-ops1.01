# Forensic Repo Audit: agentic-ops

**Date:** 2026-06-06 · **Scope:** entire repo · **Depth:** forensic · **Breadth:** everything · **Mode:** read-only (nothing modified, staged, installed, or deployed)

> Generated by an internal read-only forensic audit. No fixes applied. The owner decides what to act on. Two CRITICAL credential exposures are live and time-sensitive (see C-1, C-2).

## 1. Executive summary

93 findings: **3 CRITICAL, 8 HIGH, 16 MEDIUM, 66 LOW** (8 of the LOWs are clean-bill confirmations, not defects). The single most important fact: **two live client credentials are committed in plaintext and have been since the initial commit** (a Railway production Postgres password for Herbox, and a full-access Make.com API token for Meji). Both are permanently in git history; rotation is the only real remediation and should start now. Two structural issues compound the risk surface: a **systemic gated-access violation** (25 client/proposal sites ship their access codes as plaintext browser JavaScript, contradicting the repo's own `rule_gated_access.md`), and an **orphaned `@trigger.dev/sdk` dependency** that is never imported yet drags a CVSS 9.8 remote-code-execution package (`protobufjs`) plus a cluster of high/moderate CVEs into the platform build. Removing that one unused dependency clears the CRITICAL CVE and three of the eight HIGHs. The git history itself is clean: one developer, no unfamiliar collaborators, no force-pushes, uniformly high-quality commit messages.

## 2. CRITICAL findings

### C-1 · Railway production Postgres credential committed in plaintext
- **Category:** secret exposure · **Confidence:** high
- **Location:** `workspace/docs/2026-02-15 - Herbox Phase 6 Integration Testing/Checkpoint.md:157` and `:166`; added in commit `6679a53` (initial commit, the only commit carrying it)
- **Evidence:** `postgresql://postgres:Srv...rRTm@gondola.proxy.rlwy.net:58773/railway` (full 32-char password in clear, on a public Railway TCP proxy). The Railway FastAPI URL and n8n instance URL sit on adjacent lines, pinning the target.
- **Remediation:** Rotate the Railway Postgres password now (Railway > Herbox > Postgres > regenerate credentials); update the FastAPI service and n8n connection that consume it; review DB access logs for unauthorized use; consider disabling the public proxy if unused. The secret stays in history after any file edit, so rotation (not deletion) is the fix.
- **Time to act:** immediate.

### C-2 · Make.com API token committed in plaintext (Meji org)
- **Category:** secret exposure · **Confidence:** high
- **Location:** 4 current files: `workspace/clients/meji-media/automations/scripts/eu2-cell-write.py:10`, `reseed-eu2-datastores.py:20`, `docs/2026-03-03 - Meji Media Email Fix and Audit/Checkpoint.md`, `docs/2026-03-05 - Meji Media Client Org Deployment/Checkpoint.md`; introduced in commits `6679a53` and `768b9f8`
- **Evidence:** `2dc5...e696a`, used as `Authorization: Token ...` against `eu2.make.com/api/v2`. Grants full API access to the Meji Make.com org (team `2826470`): read/run/modify/delete scenarios, connections, datastores.
- **Remediation:** Revoke the token in Make.com (Profile > API > delete), issue a new one, store it in an env var/secret for the eu2 scripts. Permanent in history; rotation is the fix.
- **Time to act:** immediate.

### C-3 · `protobufjs` arbitrary code execution (CVSS 9.8) in platform dependency tree
- **Category:** vulnerable dependency · **Confidence:** high (via `npm audit`)
- **Location:** `platform/package-lock.json` (`node_modules/protobufjs`); advisory GHSA-xq3m-2v4x-88gg. Sole path is the orphaned `@trigger.dev/sdk`.
- **Evidence:** `npm audit` reports `protobufjs` critical, `fixAvailable:true`. Its only import path is `@trigger.dev/sdk` (declared `platform/package.json:16`), verified to have **zero imports** anywhere in `platform/src` or `platform/scripts`.
- **Remediation:** Remove `@trigger.dev/sdk` from `platform/package.json` and refresh the lockfile. This one deletion also clears the `systeminformation` command-injection HIGH and most of the socket.io/engine.io moderate cluster (all downstream of that unused SDK). Verify nothing dynamically requires it before removal.
- **Time to act:** within days.

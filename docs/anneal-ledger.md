# Anneal Ledger

One row per `/comd_system-dev` (anneal) cycle. The convergence record for the
self-annealing loop: it answers "is the toolkit getting sharper, or just
bigger?" across cycles.

Generated by `uv run tools/anneal-metrics.py --append` (Phase 6.5 of
`comd_system-dev`). The tool fills every column except **Top Finding**, which the
agent fills with the cycle's headline defect/decision.

Read it as a trend, not a snapshot. Convergence looks like: `NetD` trending to 0
or negative (consolidation), `ChangeSet` smaller each cycle (`Smaller? = yes`),
`Drift` and `Unres` falling. Oscillation or monotonic growth in any column is the
signal to stop tweaking that area and rethink (see the spec's convergence test).

Columns: **NetD** = net asset delta vs the prior row (negative = consolidation,
good). **ChangeSet** = distinct primitive files touched in git since the prior
cycle. **Smaller?** = is this cycle's ChangeSet smaller than the last? **Drift** =
count of documented-vs-actual mismatches. **Skills(dir/adv)** = real `skil_` dir
count / the count CLAUDE.md advertises. **Rules(files/LOC)** = file count / total
lines.

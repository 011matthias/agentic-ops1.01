The metadata run Brisken closes sections with — facts, separated by middle dots.

```jsx
<CredentialRow items={['SAP Co-Innovation Partner', 'Listed on the SAP Store', 'ISO 27001', 'SOC 1 Type II']} />
<CredentialRow items={[{ src: 'assets/badges/iso-27001-certified.png', alt: 'ISO 27001', height: 48 }]} />
```

Never bullet these, never stack them into a list, never add icons.
